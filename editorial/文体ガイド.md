# 文体ガイド（ブログの声）

書き手は「ひとり社長M」。休職・退職を経て、法人を作った本人が、同じ道を考えている人に話しかけるつもりで書く。報告書・制度の解説書・役所の案内の文体にしない。

## 基本

| 項目 | こうする | こうしない |
| :--- | :--- | :--- |
| 語尾 | です・ます体。ときどき「〜なんです」「〜でした。正直、〜」「〜ですよね」を混ぜる | 「〜である」「〜となる」「〜に当たる」「〜とされている」 |
| 一人称 | 「私」 | 「筆者」「自分は〜（を連発）」 |
| 読者 | ときどき「あなた」と呼びかける。「〜という人も多いと思います」 | 読者に命令する（「〜してください」の連発） |
| 段落 | 2〜4文で1段落。話の流れでつなぐ | 1文ごとに改行する（箇条書きのような本文） |
| 気持ち | 迷った、ほっとした、しんどかった、を一言入れる | 事実と数字だけを並べる |
| 太字 | 1つの節に1か所まで | 文の途中を何度も太字にする |
| 箇条書き・表 | 比べるとき、手順のときだけ | 説明を全部箇条書きにする |
| 制度の言葉 | 初出で一言かみくだく（「待期＝最初の3日の待ち期間」） | 法令・パンフレットの言い回しをそのまま使う |
| つなぎ | 「ところが」「でも」「結局」「ここで迷いました」 | 「なお」「また」「一方」「したがって」の連発 |

## 2つの調子を使い分ける（2026-10-09 本人決定）

| 部分 | 調子 | 目安 |
| :--- | :--- | :--- |
| 体験（そのとき何があり、どう感じ、どう決めたか） | **くだけた話し言葉** | 「毎日ですよ」「で、考え方を変えてみたんです」「またこれか……」。心の声をそのまま。短い文でテンポよく |
| 制度・お金・数字の説明 | **ていねいな話しかけ** | 上の「基本」の表と書き換え例の調子。です・ます、2〜4文の段落、初出の言葉はかみくだく |

**体験の見本（0-2 冒頭）：**
> 部署が変わって、通勤が片道2時間になりました。往復4時間です。毎日ですよ。休んでいる間に「戻ったらまたこれか……」と思った時点で、正直、復職はもう無いなと感じていました。
>
> とはいえ、休職の期限は近づいてきます。戻るか、辞めるか。ここはさすがに迷いました。
>
> で、考え方を変えてみたんです。「元気になったら戻れるか？」じゃなくて、「戻った先に何が待ってるか？」を紙に書き出してみました。

## 書き換えの例（制度・お金の部分）

**固い：**
> 退職後も受け続けるには、協会けんぽの条件を2つとも満たす必要があります。
> 一度働ける状態になると、そのあと再び働けなくなっても支給されない、という決まりです。

**この文体：**
> 辞めたら傷病手当金は止まるんじゃないか。退職を考えたとき、いちばん怖かったのはそこでした。
> 調べてみると、条件を満たせば辞めたあとも続くんです。ただ、落とし穴が一つあって、「最後だから」と退職日に出社して働ける状態になると、そこで打ち切りになることがあります。

## 査読での見方（品質基準 C5）

- 声に出して読んで、人が話しているように聞こえるか
- 1文ごとの改行が続いていないか
- 「〜となります」「〜に当たります」が1記事に3回を超えていないか
- 気持ちの一言が、節ごとに1つはあるか
