# 週の型と投稿の基本方針（2026-10-25 改訂）

このファイルが、記事と投稿の進め方の唯一の正。改善計画3「週1本の型」をここに置く。
投稿の文面は Drive の「投稿するもの（日付順・…）」文書。投稿は本人が手で行う。

## 週の型

| 曜日 | やること | だれが |
| :--- | :--- | :--- |
| 月 | 数字の確認（`数字の記録.md`）。その週に書く記事を1本決める。決め方は下の「選び方」 | Claude |
| 月〜水 | 記事を書く（write-article の手順。自動チェック→4人の査読→全員合格まで） | Claude |
| 水 | 合格した記事を本人に見せる。見せるのはURL、このブログでしか読めない部分3つ、本人にしか答えられない確認（最大3つ）だけ | Claude→本人 |
| 木 | 本人の了承後に公開。同じ日に、その記事の X 投稿3本と note 1本を作り、投稿文書に入れる。push は週に1回、ここでまとめて頼む | Claude→本人 |
| 毎日 | 投稿文書のその日の分を貼る | 本人 |

- 投稿文書は、いつも**2週間先まで**埋めておく。新しい記事の分で足りない日は、ネタ投稿のストックを書き直して使う（ストックは 10/23 の新ルール前の文なので、必ず書き直して自動チェックと査読を通す）
- 新しい記事を公開したら、X は次の日からその記事を先に出す。前から入っていた分は後ろへずらす
- 投稿文書を足すときは、Drive の現物を読み、新しい版を作って旧版を 99_アーカイブへ移す（移すのは本人の許可を得てから）
- 祝日や作業できない週は、記事を休んで投稿文書の補充だけにする。週の型を崩したら、このファイルに理由を書く

## 選び方（その週の1本）

1. `数字の記録.md` で、検索に出始めた言葉と記事を見る。既存の記事を直すほうが早ければ、その週は記事の手直しにする
2. 新しく書くなら、`記事ネタ台帳_下書き.md` の「重なりなし・汎用性あり・書けない情報なし」から上の順に選ぶ
3. A8 で承認された広告に合う記事があれば、同じ条件のものの中で先にする（広告は数字を見てから足す。改善計画5）

## 投稿の基本方針

1. 起点はブログ。X と note は、ブログの記事を知らせるために出す
2. 1日にやることは最大2つ。X のスレッド1本と、note 1本
3. X は1本のスレッドで記事の1つの判断を伝える。3投稿、1つ目にタグ1〜2個、3つ目に記事のURL。書き方は `投稿文の基準.md`
4. note は1記事につき要約1本。記事を公開した日の投稿文書に入れる
5. 広告の入った記事へ誘導する投稿には #PR を付ける
6. 予定を変えたら、このファイルを直す。チャットだけで済ませない
