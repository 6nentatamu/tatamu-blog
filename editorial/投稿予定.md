# 投稿の基本方針と予定（2026-10-13）

このファイルが、投稿についての唯一の正。予定も状況も、ここだけを見ればよい。
文面は Drive「X・note 投稿文（初回）_v5」。投稿は本人が手で行う。

## 基本方針

1. **起点はブログ。** X と note は、ブログの記事を知らせるために出す。ブログに無い内容は、この予定には入れない（本人の自由な投稿は別で、予定の外）
2. **1日にやることは最大2つ。** X のスレッドを1本、note を1本。どちらも1日1本を超えない
3. **X は、1本のスレッドで記事の1つの判断を伝える。** 3〜4投稿。1投稿目にタグ1〜2個、最後の投稿に記事のURL。同じ記事から、切り口を変えて何本か出してよい
4. **note は、1記事につき要約1本。** 記事と同じ番号で管理する。番号の若い順に出す
5. **新しい記事を公開したら、X は次の日からその記事を先に出す。** note は番号順のまま
6. **呼び方は記事の名前でそろえる。** 「〇日目」「①②③」のような別の番号は使わない
7. **手持ちが3日分を切る前に、Claude が次の文面を出す。** 案はチャットで示し、決まったら Drive の文書に1回で足す
8. **予定を変えたら、このファイルを直す。** チャットだけで済ませない
