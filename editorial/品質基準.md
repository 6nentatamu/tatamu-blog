# 記事の品質基準（公開してよいかの判定表）

本人に見せる前に、この表で**全項目「合格」**になるまで直す。本人は品質の検査役ではない。本人に見せるのは「合格した記事」と「本人にしか答えられない質問」だけ。

## A. このブログでしか読めない中身があるか（最重要・1つでも不合格なら書き直し）

| # | 基準 | 合格の条件 | 不合格の例 |
| :--- | :--- | :--- | :--- |
| A1 | 実数がある | 計画資料（`マイクロ法人設立計画/` の各号・SSoT）の**実際の数字**が、判断の根拠として最低3つ入っている | 「保険料が高い」「得になる」だけで金額がない |
| A2 | 比べた選択肢と、捨てた理由がある | 自分が選ばなかった案を、数字か具体的な理由つきで書いている（37号 §1-1 の却下案、39号などを使う） | 選択肢の表を置いただけで、なぜ捨てたかがない |
| A3 | 自分の判断の分かれ目が書いてある | 「ここで迷った」「この数字を見て決めた」という分岐点が1つ以上ある | 結論だけで、決めた瞬間がない |
| A4 | 想定外・失敗・後悔がある | 計画と違ったこと、やり直したこと、今ならこうする、が1つ以上ある | すべて順調だったように読める |
| A5 | 公式情報の要約が主役になっていない | 制度の説明は本文の3割以下。体験と数字の途中で、必要な分だけ出す | 公式サイトの言い換えが大半 |

## B. 読者が動けるか

| # | 基準 | 合格の条件 |
| :--- | :--- | :--- |
| B1 | 読者のタイプ別の答え | 「こういう人はこう」が2タイプ以上ある（自分と違う状況の人への答え） |
| B2 | 読者が自分で計算・確認できる | 自分の数字で確かめる方法（計算式、見るべき書類、窓口で聞くべき一言）がある |
| B3 | 次に読む記事 | 連載の次の記事へ、読む理由つきでつながっている |

## C. 文章

| # | 基準 | 合格の条件 |
| :--- | :--- | :--- |
| C1 | 型に頼らない | 「この記事で分かること」の定型ブロックを使わない。冒頭3行で場面か結論に入る |
| C2 | 念押しを重ねない | 「医師に相談」「自治体で確認」は記事に1回まで（共通の免責文が末尾にある） |
| C3 | 1文1つ | 1文に1つのこと。60字を超える文は分ける |
| C4 | タイトル | 32字以内。検索される語を前に、体験の特徴を後ろに |
| C5 | 文体 | `editorial/文体ガイド.md` に合っている。話しかける調子で、1文ごとの改行をしない、気持ちの一言がある |

## D. 守ること（1つでも違反なら公開不可）

| # | 基準 |
| :--- | :--- |
| D1 | 会社名・地名・勤務先・業種・具体的な年月日・年齢（層が分かる数字を含む）を書かない |
| D2 | 制度の事実は公式ソースで確認済み。確認できない点は断定しない |
| D3 | 計画資料の数字は最新版（SSoT・37号）と一致 |
| D4 | 読者の判断材料にならない細かい項目（数百円の収入・交通費など）は載せない |
| D5 | アフィリエイトを含む記事は `pr: true` |
| D6 | ビルド後のHTMLに `**` が残っていない（`**「…」**` や `**…。**` は太字にならない。「**…**」、**…**。の形にする） |
