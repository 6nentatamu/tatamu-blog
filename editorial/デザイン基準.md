# デザイン基準（見た目の品質）

文章の品質基準（`品質基準.md`）と同じく、**この基準に合格するまで本人に見せない**。判定はパソコン幅（1280px）とスマホ幅（375px）、ライトとダークのスクリーンショットで行う。広告の見た目と置き場所は `広告配置.md`。

## 決め方（2026-10-17 本人指示）

- **色・形・部品の見た目を、メインの独断で決めない。**実例を見たうえで専門家会議（別々のエージェントが案を出し、突き合わせる）で決める
- 実例のサイトは、**見る理由を1行書いてから**開く。理由のないブラウジングはしない
- 指摘は、指摘された1か所だけでなく**同じ種類の部品すべて**に当てはめる
- 本人に見せる前に、自分でスクリーンショットを撮って見た目を検査する

## 方針（2026-10-17 刷新）

**白い紙面と深緑1色で、読む構造が見えること。**飾りではなく、見出し・区切り・余白で強弱を付ける。

- 旧方針「手帳・記録ノート」の小道具（方眼の地、付箋、テープ、スタンプ、黄色のマーカー）は**廃止**
- 「あっさりしすぎ」は飾りが足りないのではなく、**読む構造が見えない**という意味だった（2026-10-17）
- 逆に区切りや装飾を増やしすぎると、**重要な部分が埋もれる**（2026-10-17 夜の指摘。結論ボックスで未解決、下の「未解決」）

## 配色

色は `src/styles/global.css` の変数で持ち、部品に色コードを直書きしない（アイキャッチ `src/lib/og.ts` を除く）。

| 役割 | 色（ライト） | 変数 | 使い分け |
| :--- | :--- | :--- | :--- |
| 地 | #eef3f1 | `--canvas` | ページの地（薄い緑灰） |
| 紙面 | #ffffff | `--bg` / `--card` | 本文を載せる白い面 |
| 文字 | #1c2421 | `--text` | 本文。補足は `--muted` #59645f |
| 主色 深緑 | #0f5c4d | `--accent` | 見出しの線、結論の枠、表の上線、リンク。淡い面は `--accent-soft` #eef5f2 |
| 珊瑚 | #ff6b4a / 文字用 #b93216 | `--aff-*` / `--deadline*` | **広告と「今年・締切」の1点だけ。**飾りに使わない。#ff6b4a を文字色にしない |
| 部の色 | `--c-prequel` ほか | | 記事カードの部の名前などの小さな印だけ |

- ダークモードは同系（地＝墨緑、主色＝明るい緑）。値は global.css の `prefers-color-scheme: dark`
- 深緑のベタ塗りに白い文字の大きな面（ボタン・フッター・結論）は使わない（2026-10-17 本人指摘）

## アイキャッチ（OG画像）（2026-10-18 専門家会議＋実例で決定）

`src/lib/og.ts` がビルド時に作る。1200x630。共有時の画像と、記事一覧のカードを兼ねる。

- 白地に、左端の細い深緑の線（16px）だけ。方眼・太い帯・6マスの目盛り・珊瑚・明朝・数字の枠は使わない
- **タイトルが主役。**太いゴシック68px（3行なら64px、数字ありで3行なら58px）、色は文字色
- 上の段に、部の名前と「○年目」（前日譚は「設立前」）を深緑の30px。右上にブログ名とアイコン
- 代表の数字（`keyNumbers[0]`）があれば、タイトルの下に深緑で大きく（88px）、上に小さなラベル
- 改行は「：」「？」の後で必ず行を変え、各行の長さをそろえる。1文字だけの行、単語の途中（カタカナ語など）での改行は出さない
- 判定：全記事の画像を並べて見る。スマホの一覧（幅約343px）でタイトルと数字が読めること。本番はサーバーの書体で横に広く出るので、本番の画像でもはみ出しがないか見る
