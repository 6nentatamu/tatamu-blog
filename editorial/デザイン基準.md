# デザイン基準（見た目の品質）

文章の品質基準（`品質基準.md`）と同じく、**この基準に合格するまで本人に見せない**。判定はパソコン幅（1280px）とスマホ幅（375px）のスクリーンショットで行う。

## 目指す水準

日本の個人のお金・制度系ブログで、よく読まれているものの標準装備を下回らないこと。「文字だけのページ」は不合格。

## サイト全体

| # | 基準 | 合格の条件 |
| :--- | :--- | :--- |
| S1 | トップの第一印象 | ファーストビューに、サイトの主題が一目で分かる図（6年の目盛りと「今どこにいるか」）と、キャッチコピー、はじめにへの導線がある |
| S2 | 記事カード | 一覧（トップ・カテゴリ・タグ）は、アイキャッチ画像つきのカード。タイトル・部の名前・読了時間が見える |
| S3 | 運営者の顔 | 記事の末尾とサイドバーに、プロフィールボックス（アイコン・ペンネーム・3行の自己紹介・Xへのリンク） |
| S4 | 配色と余白 | 下の「配色と世界観」の色（主色＝深緑 #0f5c4d）を見出し・ボックス・ボタンで一貫して使う。白一色の単調な画面にしない |
| S5 | スマホ | 375px で横にはみ出さない。文字16px以上。表は横スクロール |

## 配色と世界観（2026-10-11 本人決定）

**配色＝案2（深緑×珊瑚）、方向性＝C（手帳・記録ノート）。** 旧ブランド色（深い青緑 #1f6f6a・朱 #c8553d）は廃止。色は `src/styles/global.css` の変数で持ち、部品に色コードを直書きしない（アイキャッチ `src/lib/og.ts` と付箋の固定色を除く）。

| 役割 | 色 | 変数 | 使い分け |
| :--- | :--- | :--- | :--- |
| 主色 深緑 | #0f5c4d | `--accent` | h2 の帯、ボタン、リンク、結論ボックス、集計表の上線、スタンプ「設立」。上の文字は白（`--on-accent`） |
| 差し色 珊瑚 | #ff6b4a | `--deadline` | 「今年」「いまここ」「解散予定」の強調と、装飾（h2 左のタブ、h3 の短い下線、ボタンの影、集計表の縦線）。**塗りに使い、上の文字は墨**（白文字は不可。コントラスト不足） |
| 珊瑚の文字用 | #b93216 | `--deadline-ink` | 珊瑚を文字色にするとき（「1年目」など）。#ff6b4a をそのまま文字に使わない |
| 紙 | #fff6e9 | `--bg` | ページ地（薄い方眼 `--grid` を重ねる）。本文は無地の紙 `--card`（#fffdf8）に載せる |
| 墨 | #1b1b1b | `--text` | 本文 |
| 明るい黄 | #ffd166 | `--memo` / `--marker` | 付箋（体験メモ・連載の付箋・テープ）と、太字・小見出しのマーカー。上の文字は墨 |

- 手帳の部品：方眼の地、罫線の集計表（トップの数字3つ・記事の「この記事の数字」）、罫線ノートの年表（トップ）と小型のマス（ヘッダー・記事の「○年目」）、スタンプ、付箋。
- ボックス：ポイント＝深緑のノート（左に二重線）、注意＝珊瑚、体験メモ＝黄色の付箋（テープ留め）。
- **前日譚（prequel）では「今年」の強調に珊瑚を使わない**（マスと「設立前」は深緑）。珊瑚を装飾の差し色として使うのは可。
- アイキャッチは部ごとに帯の色を変える（前日譚＝灰緑、構想＝深緑、設計＝青緑、設立＝墨緑、運用＝黄、月次＝墨）。右側は方眼の紙。
- ロゴ（6本の目盛り）：経過＝珊瑚の塗り、残り＝深緑の線、地＝紙。
- ダークモードは同系（地＝墨緑、主色＝明るい緑、珊瑚と黄はそのまま）。
- 年表・目盛りに年月日や設立月は出さない（品質基準 D1）。「1年目 設立・届出・口座／2〜5年目 運営／6年目 解散・清算」まで。

## 記事ページ

| # | 基準 | 合格の条件 |
| :--- | :--- | :--- |
| P1 | アイキャッチ | 記事ごとに、タイトルと部の名前を入れた画像が冒頭にある（共有時の画像にも使う） |
| P2 | 結論が先に見える | 冒頭に「この記事の結論」ボックス（3行以内）。定型の「分かること」ではなく、結論そのもの |
| P3 | 目次 | 見出しが4つ以上の記事は、冒頭に目次 |
| P4 | 図 | 数字を比べる記事は、最低1つの図（棒グラフ・表の図解・流れ図）。数字の表だけで終わらせない |
| P5 | 強調の部品 | 「ポイント」「注意」「体験メモ」などのボックスで、本文の山場を目で拾えるようにする（1記事に2〜4個） |
| P6 | 見出し | h2 は帯や左線で一目で区切りが分かる。h3 と見分けがつく |
| P7 | 記事の終わり | プロフィール → 連載の前後 → 関連記事カード（アイキャッチつき）→ Xでシェア の順 |

## 判定のしかた

1. 1280px と 375px で、トップ・記事1本（図のある記事）・連載目次をスクリーンショットする
2. 上の表を1項目ずつ当て、合否と直す点を書く
3. 全項目合格までくり返す。本人には合格後のスクリーンショットを見せる
