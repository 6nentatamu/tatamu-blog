マイクロ法人を作ると、会計だけでなく、給与計算、年末調整、社会保険の手続きまで、自分でやることになります。それぞれ別のソフトや窓口で済ませると、覚えることが増えていくんですよね。

マネーフォワード クラウドは、これをまとめて引き受けるサービスです。この記事は、ほかの人にとって使いやすいかという目線で、公式の情報をもとにまとめたものです。

## ひとり法人プランで使えるもの

ひとりで経営する法人向けには「ひとり法人プラン」があります。年払いで税込32,736円、月払いなら税抜3,980円です。使える人は、税理士などのアカウントを除いて1人に限られます。

このプランには、12のサービスがセットで入っています。

マイクロ法人でも、役員報酬を払うと給与計算と年末調整が毎年あります。社会保険の書類もあります。これが会計と同じサービスの中で済むのが、いちばんの使いやすさだと思います。

## 年末調整から1月の書類まで、同じサービスで作れる

マイクロ法人の給与まわりで手間がかかるのは、年末から1月です。年末調整をして、1月31日までに書類をそろえます。

  { title: '12月：年末調整', note: 'クラウド年末調整が年税額を計算する' },
  { title: '1月：源泉徴収票', note: '役員本人に渡す' },
  { title: '1月31日まで：給与支払報告書', note: '役員が住む市区町村へ出す' },

クラウド年末調整では、源泉徴収票、給与支払報告書、法定調書合計表を作れます。公式の帳票の案内では、この3つは電子申告にも対応しています。電子申告の機能は年度ごとに提供されるので、その年の対応は公式のお知らせで確かめます。電子申告には、e-Tax と eLTAX の利用者登録と、ファイル形式の電子証明書を用意します。

毎月の給与のほうは、クラウド給与が社会保険料と所得税を計算します。源泉所得税を納める「所得税徴収高計算書」も出力できます。半年分ずつ納める「納期の特例」用の帳票もあります。

社会保険の届出は、クラウド社会保険で作れます。毎年7月の算定基礎届のほか、報酬が大きく変わったときの月額変更届も作れます。賞与を出したときの賞与支払届もあります。届出は、e-Gov などでの電子申請に対応しています。

## 銀行の明細は、連携で取り込める

マイクロ法人でよく使われるネット銀行も、連携先にあります。[公式の連携先一覧](https://accounting.moneyforward.com/service_catalog)には、ドコモSMTBネット銀行と三井住友銀行が、法人の口座として載っています。

使う予定の口座が連携先にあるかは、この一覧で銀行名を探すと確かめられます。口座を作る前に見ておくと、記帳の段取りが立てやすくなります。

仕訳の上限の年500件に収まるかは、通帳とカードの明細が1年で何行になるかで見当がつきます。

## 向いている人

- 経理をできるだけ1か所にまとめたい人：会計、給与、年末調整、社会保険の書類を、同じサービスの中で回せます
- 申告は税理士に頼む人：会計は決算書まで作れれば足ります。頼む税理士が同じサービスを使っていれば、データの受け渡しも楽です
- 銀行やカードの明細を自動で取り込みたい人：公式では、2,300以上の金融関連サービスと連携できるとしています
- 法人と個人事業の両方をする人：個人向けの確定申告も同じシリーズにあります

## 申告まで自分でやる人は、ソフトを1つ足す

法人税の申告書は、マネーフォワード クラウド会計では作れません。公式のよくある質問でも、法人税の申告には対応していないと案内しています。申告まで自分でやりたい人は、申告書を作れる別のソフトを足します。申告だけ税理士に頼む方法もあります。

比べる先を探している人には、<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEMLQ+8SQMLU+35XE+6IP2Q">弥生会計 Next</AffLink>もあります。0円の無料体験プランで最大2か月試せて、年額は税抜34,800円からです。こちらも、法人税の申告書は連携する別のソフトで作る案内です。

## 始め方

1か月の無料トライアルがあります。クレジットカードの登録はいらず、無料期間が終わっても自動で有料にはなりません。1事業者1回までです。

## これから会社や個人事業を始める人へ

会社をまだ作っていない人は、<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEIPF+CCQTO2+4JGQ+HV7V6">マネーフォワード クラウド会社設立</AffLink>で、設立に必要な書類を無料で作れます。株式会社と合同会社のどちらにも対応しています。

個人事業を始める人は、マネーフォワード クラウド開業届が無料です。開業届と青色申告の承認申請書などを、フォームに入力して作れます。

個人の確定申告には、マネーフォワード クラウド確定申告があります。いちばん安いパーソナルミニプランは年払いで税抜10,800円です。e-Taxで申告すれば、青色申告で最大65万円の控除に対応しています。スマホのアプリからも申告できます。
