設立費用は、計画の見積もり5.0万円に対して、実額68,590円でした。差は+1.86万円。原因は、自分で決めたことを見積もりに反映し忘れていた、というなんとも締まらない話です。

## 設立費用：見積もり5.0万円、実額6.86万円

| 項目 | 見積もり | 実額 |
| :--- | ---: | ---: |
| 登録免許税（法務局に納める税金） | 30,000円 | 60,000円 |
| 電子定款の作成サービス | 5,000円 | 5,500円 |
| 印鑑など | 15,000円 | 3,090円 |
| **合計** | **50,000円** | **68,590円** |

印鑑などの実額は、法人印鑑3本セット2,220円と、郵便受けの表札870円です。ここは見積もりより1.2万円ほど安く済みました。

<Memo title="体験メモ">

差のほとんどは登録免許税です。見積もりは、自治体の創業支援（特定創業支援等事業）で半額の3万円になる前提でした。ところが、その創業支援は「受けない」と先に決めてたんですよ。決めたあとで、資金計画の見積もりを直してなかった。実額を計画に入れたときに「あれ？」となって、やっと反映漏れに気づきました。

</Memo>

### 創業支援を受けなかった判断

受ければ、登録免許税が3万円安くなります。それでも受けなかったのは、受講の条件が「1ヶ月以上かつ4回以上」だったからです。修了の証明書を待つと、設立が1ヶ月遅れます。

自分の場合で比べると、こうなりました。

- 受ける：登録免許税3万円＋受講料4,000円＝3.4万円
- 受けない：登録免許税6万円。ただし社会保険に1ヶ月早く入れるぶん、0.5〜1.3万円ほど戻る
- 差：受けるほうが1.3〜2.1万円有利。そのかわり、受講と窓口で10〜13時間かかる

時給にすると1,200〜1,900円。うーん、微妙です。ここはけっこう迷いました。決め手は、6年間の計画全体の試算でした。計画の成否を大きく左右するのは生活費で、1〜2万円の差はほとんど効かないんです。だったら準備に時間を使うほうがいい、と決めました。

創業支援の効果は、登録免許税だけではありません。創業融資の自己資金要件の緩和などもあります。借入をする予定の人なら、結論は変わると思います。自分は借入をしない方針なので、捨てたのは3万円の減税だけでした。

ほかにも、差を小さくする事情が3つありました。

- セミナーの受講料は自治体しだい：無料のところもあれば、費用がかかるところもあります。自分の自治体では4,000円で、そのぶん減税の効果が目減りしました
- 合同会社は、もともと減税額が小さい：登録免許税の最低額は、株式会社が15万円、合同会社が6万円です。半額になって浮くのは、株式会社なら7.5万円、合同会社なら3万円です。合同会社では、受ける・受けないの差がさらに縮みます
- 電子申請との相性：私が検討した弥生の会社設立サービスでは、電子申請で創業支援の証明書を使う申請ができませんでした。創業支援を受けるなら、申請の方法から選び直す必要がありました

### 電子定款は外さなかった

<Point>

紙の定款なら、収入印紙4万円がかかります。電子定款の作成サービスは5,500円でした。設立時期の差は1〜2万円でしたが、こちらは4万円の差です。

</Point>

役員報酬45,000円のうち、手取りは33,607円です。11,393円は、本人負担の社会保険料として引かれます。会社負担と合わせると、社会保険料は月23,102円です。所得税は、この額だとかかりません。

### 役員報酬を下げる案は捨てた

当初は、2年目から役員報酬を月1.5万円に下げる計画でした。社会保険料は、報酬を下げても同じ額です。下げたぶん、法人の支出だけが減ります。

この案は、結局捨てました。2026年3月に、役員の社会保険の加入を実態で審査する通知が厚生労働省から出たためです。月1.5万円だと、会社が払う社会保険料（労使で約2.3万円）が報酬を上回ります。加入を否認されるリスクが高いと判断しました。据え置くことで、6年で約14万円多くかかります。

## 年でいくらになり、どう賄うか

そもそも法人にした理由（FIREとの年あたりの差）は、[前日譚の最終回](/posts/prequel-5-hojin/)に書きました。計画上の、法人の1年間の支出（2年目以降）はこうです。

| 項目 | 年額 |
| :--- | ---: |
| 役員報酬 | 54.0万円 |
| 社会保険料（会社負担分） | 14.1万円 |
| 法人住民税の均等割 | 7.0万円 |
| 会計ソフト | 2.6万円 |
| AIツールとクラウド | 5.17万円 |
| **合計** | **82.8万円** |

この1か月の実績を12倍すると、毎月の3項目で約73.3万円です。毎月は出ない均等割と会計ソフトの9.6万円を足すと、約82.9万円です。計画とほぼ一致しました。

小さなずれが1つあります。通信費は計画では月4,311円でしたが、実額は4,414円でした。月103円の差で、年でも約1,200円です。計画を直すほどの額ではないので、そのままにしています。

賄うのは、設立時に入れた300万円です。内訳は、資本金100万円と、自分から会社への貸付200万円です。これを法人で投資信託にして、毎年取り崩します。

<Caution>

ただし、300万円では6年間の支出を賄いきれません。役員報酬を据え置いたことで、6期と清算期の支出は合計約510万円になりました。計画どおりに進んでも、4年目から会社への追加の貸付が要ります。試算では合計189.1万円です。もとは自分の資産なので、家計全体で見れば財布を移しているだけです。

</Caution>

## 自分の場合で確かめるなら

- 設立費用：合同会社の登録免許税は、資本金×0.7%と6万円の大きいほうです。資本金が約857万円までなら6万円です。創業支援を考えるなら、自治体の窓口で「証明書の発行まで、受講開始から何日かかりますか」と聞いてください。設立が何ヶ月遅れるかが分かります。
- 毎月の固定費：役員報酬を最低限にする場合、社会保険料は報酬額にかかわらずほぼ一定です。会社負担分×12に、均等割（資本金1,000万円以下なら標準で年7万円）と会計ソフト代を足してください。最低限の年間維持費が出ます。

役員報酬を4.5万円にした理由と、下げる案を捨てた経緯は、第2部「役員報酬をいくらにしたか」で詳しく書く予定です。
