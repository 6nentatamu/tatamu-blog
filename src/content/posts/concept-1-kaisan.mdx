会社を作る前に、会社のたたみ方を決めました。順番が逆に見えますよね。でも、ここを先に決めないと、作るかどうかの計算が閉じなかったんです。

私の法人の役目は1つです。証券口座にたまった含み益、つまり買ったときより値上がりしている分を、少しずつ売って現金に変えること。法人なしで売ると、売った利益のぶんだけ翌年の国民健康保険、略して国保が上がります。

法人の役員なら会社の健康保険に入るので、いくら売っても保険料は変わりません。くわしくは[前日譚の最終回](/posts/prequel-5-hojin/)に書きました。

役目が終わると、私の会社には社会保険と維持費で年約37.3万円かかります。だから「いつ終わるか」は、最初から計画の一部でした。

## 8年で組んだ最初の計画を、6年に直した

最初に引いた線は、8年でした。含み益をすっかり処理し終えるまで法人を続けて、そのあとは国保に入る。そういう計画です。筋は通っているように見えました。

ところが、試算を見直していて、穴に気づきます。**国保は前年の所得で決まる**んです。法人をたたんだ翌年の国保には、法人があった最後の年に売った利益が、丸ごと乗ります。

<Memo title="体験メモ">

「国保は売った利益に連動する」。これは、私が法人を作る理由にした仕組みです。たたむときにも同じ仕組みが働くのに、最初の計画には入れていませんでした。

計算し直すと、私の場合、解散の翌年の国保と国民年金は合わせて年約51.3万円でした。法人なしで暮らすのと、ほとんど同じ水準です。

</Memo>

同じ見直しで、もう1つ漏れが見つかりました。高齢になってから払う介護保険料を、計算に入れていなかったんです。私の試算では、生涯で約223万円でした。

この2つを直すと、将来の資産の見通しは、私の試算で約437万円下がりました。見落としを先に直せたので、計画の数字は実態に近づきました。

## たたんだあとの健康保険は、任意継続にする

国保が跳ねるのは、解散の翌年と、その次の年の途中までです。この「高い2年」をどうしのぐか。答えは、会社を辞めたときと同じ、任意継続でした。

任意継続は、会社の健康保険に、抜けたあとも最長2年入り続けられる制度です。保険料は、抜けたときの等級で決まります。等級とは、報酬の額を区切った段階のことです。そのあとにいくら株を売っても、変わりません。

私の役員報酬は月4.5万円で、等級はいちばん下。だから保険料もいちばん安い段階です。次の表は、私の場合の数字です。国保の約30.2万円は、解散の前の年に私が利益を確定した場合の、解散の翌年の国保の試算額です。

| 解散の翌年の負担 | 国保を選ぶ | 任意継続を選ぶ |
| :--- | ---: | ---: |
| 健康保険 | 約30.2万円 | 約8.0万円 |
| 国民年金 | 約21.1万円 | 約21.1万円 |
| **合計** | **約51.3万円** | **約29.1万円** |

差は年約22万円で、任意継続に決めました。しかも、任意継続の上限は2年。国保が高い期間を、ちょうど覆えます。

2年たって国保に移るころには前年の所得が小さくなっているので、保険料は安い段階で入れます。

<Caution>

任意継続は、会社の健康保険を抜けた日から20日以内に申し込むと入れます。期限を過ぎると選べなくなります。解散の手続きでいちばん忙しい時期に期限が来るので、私の予定表では、解散日の次に大きく書いてあります。

</Caution>

会社の解散で健康保険を抜ける場合も、任意継続は使えるのか。調べてみると、扱いはふつうの退職と同じです。

健康保険法では、任意継続に入れるのは「会社に使われなくなって資格を失った人」です。辞めた理由は問われません。会社をたたんで役員でなくなるのも、これに当たります。

条件は2つだけです。抜ける前に続けて2か月以上入っていること。そして、20日以内に申し込むことです。

## 解散後も「年43万円の枠」が残る

健康保険の見直しをしていて、もう1つ見つけました。法人をたたんだあとも、売っていい枠が残っているんです。

国保には、所得の少ない世帯の保険料を7割下げる軽減があります。基準は、世帯の所得の合計が43万円以下であることです。これは、給与や年金を受け取る人が世帯に1人までの場合の基準です。住民税の基礎控除も43万円です。つまり、**売った利益が年43万円までなら、税も国保も増えません**。

私の会社がある間は、社会保険と維持費で年約37.3万円を払って、この枠のぶんを売ります。解散後の枠は、タダで使えます。

含み益を全部処理し終えるまで、法人を続けなくていい。少し残してたたんで、残りはタダの枠で数年かけて処理すればいいんです。

ここで計画が8年から縮みました。6年目の終わりにたたむと、私の試算では含み益が約142万円残ります。それを年43万円ずつ、4年ほどで処理します。

## 比べた案と、捨てた理由

決めるまでに、いくつもの案を同じ道具で比べました。ものさしは、私の試算の、いちばん最後の年の総資産です。採用した案を0として、差を並べます。

| 案 | 採用案との差 | 捨てた理由 |
| :--- | ---: | :--- |
| **6年でたたむ・任意継続・解散後は年43万円（採用）** | **0** | — |
| 毎年売る額を少し増やして、6年で処理しきる | 約▲30万円 | 43万円の枠を使えば急ぐ必要がない。税が増えるだけ |
| たたむのを1年遅らせる（任意継続にはする） | 約▲62万円 | タダの枠を使い始めるのが遅れ、社会保険と維持費も1年分よけいにかかる |
| 含み益を処理せず、先送りする | 約▲101万円 | 先送りしても税率は同じ。タダの枠を捨てることになる |
| 国民年金を払い終える年まで、法人を延ばす | 約▲133万円 | 払わずに済む国民年金より、法人にかかるお金のほうが大きい |
| 6年でたたむが、解散後は国保にする | 約▲154万円 | 解散の翌年に国保が跳ねる |
| 法人を最後まで続ける | 約▲1,444万円 | 役目が終わったあとも、お金だけが出ていく |

最後まで比べたのは、「国民年金を払い終える年まで延ばす」案でした。法人にいる間は厚生年金に入るので、国民年金を自分で払わずに済みます。延ばせば延ばすほど得に見えるんですよね。

でも並べてみると、私が払わずに済む国民年金は年約21万円。私の会社にかかる社会保険と維持費は年約37.3万円です。差は毎年16万円で、延ばさずにたたむほうが安くつきます。

「最後まで続ける」案は、採用案より約1,444万円少なくなりました。法人は、一度作ると「せっかくだから」と続けたくなると思います。役目が終わったら閉じると先に決めておけば、この差は避けられます。

## 解散そのものにかかる時間とお金

解散の手続きは、最低でも3か月かかります。会社にお金を貸している人に向けて、国が出している広報紙の官報に、お知らせを2か月以上載せる決まりがあるためです。ここは短くできません。

私の予定はこうです。

1. 事業年度の最後の日に、解散を決める。年度の途中でたたむと、申告が1回増えるためです
2. 2週間以内に、解散と清算人の登記をする。清算人は会社の後始末をする人で、私がなります
3. 年金事務所に、会社の社会保険をやめる届けを出す
4. 会社の健康保険を抜けた日から20日以内に、健康保険の窓口へ任意継続を申し込む
5. 官報にお知らせを、2か月以上出す
6. 解散から2か月以内に、解散した年度の確定申告をする
7. お知らせの期間が終わったら、後始末が済んだことの登記、つまり清算結了と、最後の確定申告をする

実費は、登記が合計41,000円、官報が約3〜4万円で、合わせて約7〜8万円です。私が自分でやる前提の金額で、専門家に頼めば別に報酬がかかります。

<Point>

お金の面では、もう1つ仕掛けがあります。私は会社に200万円を貸しています。これを「返さなくていい」とすると、会社の儲けとして扱われるんです。

ただ、それまでに積み上がった赤字のほうが大きいので、法人税はかかりません。法人税がかからない差額は、約57.4万円です。この計算は、赤字を翌年以降に繰り越せる「青色申告」が前提なので、設立のときに承認の申請を出しました。出口の税金の話は、[資本金の記事](/posts/design-2-shihonkin/)に書きました。

</Point>

## 「6年」は決め打ちではない

ここまで書いておいて何ですが、6年はいまの見立てです。暴落で売れない年が続けば、含み益の処理は遅れます。私が代表を退き、配偶者を代表にして法人を残す案も、検討しています。

それでも、先に線を引いておく意味はあると思っています。線があるから、毎年「予定どおり進んでいるか」を確かめられます。役目が終わった時点で、決めたとおりに閉じられます。

## あなたの場合はどうか

私と同じ形の人は、少ないかもしれません。それでも、考え方は使えると思います。たたむ時期は、法人の役目によって変わります。

- 含み益の処理が目的の人：処理が終わる年が、たたむ年の目安です。全部終わるのを待たず、解散後の年43万円の枠で残りを処理する手があります
- 配偶者が会社に勤めている人：解散後に配偶者の扶養に入れれば、健康保険も国民年金も負担がなくなります。私の試算では、任意継続よりさらに約135万円有利でした。順番は、先に任意継続を申し込んでから、扶養の申請です。逆だと、扶養が通らなかったときに20日の期限が過ぎています
- 事業の売上がある人：法人の役目が保険料の節約だけではないので、この記事の計算は当てはまりません。「売上がなくなったら、たたむか」を先に決めておくと、やめどきで迷いません
- まだ作っていない人：作る前に、たたむ費用の約7〜8万円と、解散の翌年の健康保険まで計算に入れてみてください。入れても得なら、作る価値があります

### 自分の数字で確かめる方法

法人をまだ作っていない人も、次の4つで目安が出せます。比べるのは年額です。

1. たたむ前の年に、いくらの利益を確定するかを書く。売った金額ではなく、売った金額から買った金額を引いた「利益」です。配当も足します
2. 住んでいる市区町村のサイトで「国民健康保険料 計算方法」を探す。見るのは、所得割という所得に応じてかかる分の率と、均等割という1人ごとにかかる分です。率は医療分と支援金分を足します。40歳から64歳の人は、介護分も足します。1の利益から43万円を引いた額に、所得割の率を掛けて、均等割を足します。これが、解散の翌年の国保の目安です
3. 任意継続の保険料を見る。協会けんぽなら、都道府県ごとの「保険料額表」で、役員報酬に当たる等級の行の「全額」の欄です。月額なので12倍します。まだ作っていない人は、決めるつもりの役員報酬を当てはめてください。任意継続は会社の負担がなくなるので、折半の額ではなく全額を払います
4. 2と3を比べる。国保のほうが高ければ、任意継続を選ぶ理由があります。国民年金はどちらでも同じ額なので、比べなくてかまいません

国保は、世帯の人数や軽減で変わります。正確な額は、役所の国保の窓口で「前年の所得が◯万円だと、保険料はいくらですか」と聞くと、試算してもらえます。

## 次は、設立にいくらかかったか

たたむ費用が約7〜8万円なら、作る費用はいくらだったのか。次の記事では、設立にかかったお金を、使ったサービスごとに全部書きます。合計だけ先に知りたい人は、[1年目・第1回の収支](/posts/monthly-y1-01/)をどうぞ。
