資本金100万円と、私が会社に貸す200万円。会社のこの300万円を、投資信託で運用します。そのためには、会社の名前で証券口座を開かないといけません。

先に結論を書くと、ひとり法人でも証券口座は開けます。私はSBI証券の法人口座を、申し込んでから約1か月で開設しました。ただ、個人の口座のようにスマホで終わる手続きではありませんでした。

## 証券口座より先に、銀行口座が要る

法人の証券口座は、入出金に法人名義の銀行口座を使う前提です。SBI証券では、出金先は法人名義の口座に限られます。申込でも、出金先の銀行口座を入力します。

なので順番は、銀行口座が先です。私はネット銀行の法人口座が開いたその日に、SBI証券の申込書を取り寄せました。

電話番号は、携帯で大丈夫でした。SBI証券の開設条件には固定電話とありますが、続けて、ない場合は代表者名義の携帯などでよいと書かれています。銀行の3つも、すべて携帯で通りました。

## 申込は郵送で、書類はほとんど手書き

SBI証券の法人口座は、ウェブで請求すると申込書が郵送で届きます。そこに記入して捺印し、書類を同封して送り返す流れです。公式の目安は、請求から約5営業日で申込書が届き、返送から約10日で開設です。私のところには、請求から2日ほどで届きました。

同封する主なものは次のとおりです。最新の一覧は、公式の必要書類のページで確かめてください。

| 書類 | 中身 |
| :--- | :--- |
| 会社の登記簿謄本 | 原本 |
| 法人の印鑑証明書 | 原本。発行から6か月以内 |
| 代表者の本人確認書類 | 2種類。コピーで可、今の住所が載っているもの |
| 実質的支配者の申告書 | 会社を実際に支配している人の届け。ひとり法人なら自分 |
| FATCA確認書 | 米国の納税義務に関する確認の書類 |

本人確認書類は、計画のときの私の調べでは1点でした。SBI証券の今の案内では2種類です。もう一つ見込み違いがありました。書類はアップロードで出せて往復が少ないと見ていましたが、実際は郵送でした。申込書に法人番号の13桁を書く欄もあるので、国税庁から届く法人番号の通知も手元に置いておくと早いです。

手間がかかったのは、手書きの量でした。個人の口座なら画面で選ぶ項目を、法人では会社名や住所まで、紙に一つずつ書きます。見直しは必須です。

## 記入の誤りで、1回差し戻された

私は1回、差し戻されました。返送してから2週間ほどたって、記入に誤りがあると書類が戻ってきたんです。直してもう一度送り、そこから2週間ほどで開設の書類が届きました。

計画を立てたとき、法人の証券口座は2〜4週間と見ていました。実際は約1か月で、保守的に見た側に近い結果です。

開設したあとにも、もう一つつまずきました。銀行と証券をつなぐ連携を申し込んだら、会社名のカナが一致しないというエラーが出たんです。サポートに問い合わせると、銀行の登録名とエラーの日時と連絡先を聞かれ、その日のうちに直りました。エラーが出たら、日時を控えてから問い合わせると早いです。

## 個人の証券口座と、何が違うか

開いてみて、個人の口座との違いは3つありました。

1. **特定口座がない**。証券会社が損益を計算してくれる特定口座は、個人のための仕組みです。松井証券や三菱UFJ eスマート証券は、公式の案内に法人は対象外と書いています。損益は自分で帳簿につけます。私は年に数回しか売らない予定なので、手間は小さいと見ています
2. NISAも使えない。NISAは個人向けの制度なので、法人は対象外です。会社のお金は、非課税の枠なしで運用します
3. 投資信託を売るとき、2つの出し方を選べる。SBI証券の法人口座では、解約請求と買取請求のどちらでも売れます。解約請求は利益に15.315%の源泉徴収がかかり、買取請求はかかりません。個人の口座では、選ぶ場面はありません

3つ目は、税金が安くなる話ではありません。源泉徴収されなくても、利益には法人税がかかります。違うのは、申告で書く書類と、手元に残るお金の時期です。

## どの証券会社にするか

私がSBI証券にしたのは、運用したい投資信託を法人口座でも買えることを確かめられたからです。eMAXIS Slimのような投資信託は、証券会社ごとに取り扱いが違います。個人の口座で買えても、法人口座で買えるとは限りません。

楽天証券も予備として考えました。こちらも申込書を郵送でやりとりし、公式には書類が届いてから審査に1〜2週間とあります。私は1社に申し込む形にしました。取扱商品を見比べて、申込先を選べます。

選ぶときは、次の順で見ると迷いません。

1. 買いたい投資信託や株を、その会社の法人口座で扱っているか。投資信託の名前を、法人口座の取扱一覧で探します
2. 本店で郵便を受け取れるか。SBI証券は、登記上の本店で郵便物を受け取れることを条件にしています
3. 固定電話がない場合、携帯で申し込めるか

## こういう人は、ここに気をつける

- **本店をバーチャルオフィスにする人**は、開設の書類を本店で受け取れるかを先に確かめてください。SBI証券の完了の通知は、転送できない簡易書留で、会社宛と代表者の自宅宛に届きます
- 固定電話を引いていない人は、携帯で申し込めるかを各社の開設条件で見てください。会社によって書き方が違います
- まだ銀行口座が開いていない人は、証券口座の申込書だけ先に取り寄せても、出金先が書けません。銀行口座を先に作ります

開設までの日数は、申込書の取り寄せと返送の往復で決まります。私のように差し戻されると、2週間ほど延びます。返送の前に、法人番号の13桁、登記簿と同じ表記の会社名、捺印、同封書類の抜けを見直すのがいちばんの近道です。
