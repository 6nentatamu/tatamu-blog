会社には、設立のときに300万円を入れました。そのうち100万円を資本金に、残りの200万円は、私が会社に貸したお金にしています。会社から見ると役員借入金です。

同じ300万円なのに、なんで分けるの？　と思いますよね。この分け方で、6年後に会社をたたむときの法人税が決まるんです。先に流れだけ書くと、こうなります。

## 資本金と貸付は、戻し方がちがう

会社に入れたお金は、どちらも会社の口座で運用して、毎年の費用に使います。ちがうのは、私の手元に戻すときの道です。

| | 役員借入金（200万円） | 資本金（100万円） |
| :--- | :--- | :--- |
| 戻し方 | 会社が「返済」すれば、いつでも戻る | 解散するまで、原則戻らない |
| 戻すときの税金 | かからない（貸したお金が返ってくるだけ） | 解散のとき、資本金の額までならかからない |
| 私の計画での役目 | 必要なときに引き出せる財布 | 解散のときの法人税を防ぐ差額 |

資本金を途中で減らすこともできます。ただ、合同会社でも、官報への公告と債権者への通知をして、1か月以上待つ手続きがいります。手間が大きいので、いつでも引き出せる分は貸付にして、資本金はたたむ日まで置いておく、と決めました。

貸付の契約書は、電子契約で交わしました。貸す側の私と、借りる側の会社の両方が署名します。会社の代表も私です。紙の契約書だと、200万円の貸付には2,000円の収入印紙がかかります。電子契約なら印紙はいりません。4年目からの追加の貸付も、電子契約で覚書を交わす予定です。

## 解散のとき、資本金が効いてくる

私の会社は売上がほとんどなく、毎年赤字です。赤字は「繰越欠損金」として、10年先まで持ち越せます。持ち越した赤字は、後の年にもうけが出たとき、そのもうけから差し引けるんです。

会社のお金は、毎年の費用で少しずつ減っていきます。私の計画では、最後は会社にお金が残りません。だから私が貸したお金は返ってこないので、返してもらうのをあきらめます。これを債務免除といいます。時期は、4年目と、会社をたたむときの2回に分ける計画です。

ここで問題が1つあります。会社から見ると、返さなくてよくなった借金は「もうけ」として扱われるんです。たとえば100万円をあきらめたら、会社に100万円のもうけが出たことになります。これを持ち越した赤字で打ち消せれば、法人税はかかりません。

打ち消せるかどうかは、次の式で決まります。

```
解散のとき法人税がかからないための差額 ＝ 資本金 − 6年間の均等割の合計
```

均等割は、赤字でもかかる住民税です。私の会社は年7万円で、清算の手続き中の分も足すと、合計は約43万円です。ところが均等割は、法人税の計算では費用に入りません。払ったお金は減っているのに、その分だけ赤字が小さく数えられてしまうんです。

会社に入れたお金は、最後にはすべて使い切るか、あきらめる額になります。そのうち資本金の分は、借金ではないので、あきらめる額には入りません。だから、資本金が均等割の合計より大きければ、あきらめる額より赤字のほうが大きくなります。これが式の意味です。

<Point>

私の会社は資本金100万円なので、差額は約57万円です。運用がうまくいっても、いかなくても、私の計画ではこの差額は変わりません。運用益が増えると会社のお金が増え、そのぶんあきらめる額が減ります。同時に、運用益で赤字も同じだけ減るので、差し引きは同じになるんです。

</Point>

## 60万円で足りる計算でした。でも、やめました

式を見れば分かるとおり、資本金は均等割の合計を超えていれば足ります。実は最初の計画では、資本金を60万円、貸付を240万円にしていました。

ところが当時は会社を8年続ける計画で、そのぶん均等割の合計も大きかったんです。60万円だと、差額は数万円しか残りませんでした。均等割が年に数千円上がるだけで、消えてしまう額です。

均等割は自治体が決めるので、6年の間に上がっても私には何もできません。それなのに、差額が数千円の値上げで消える設計なのは、さすがに薄すぎる。そう判断して、資本金を100万円に上げました。

その後、会社をたたむ時期を6年に前倒ししたので、今の計画で比べると上の図のとおりです。60万円のままでも約17万円は残りますが、100万円なら約57万円。均等割が倍になっても足ります。

<Memo title="資本金を薄くしても、こんな方法があります">

資本金を均等割の合計より少なくしても、たたむときに法人税がかからない道はあります。「期限切れ欠損金」というしくみです。

会社にお金が残らない見込みでたたむ場合、期限が切れた分も含めたそれまでの赤字を、債務免除のもうけから差し引けます。ただし、先にふつうの繰越欠損金を使います。お金が残らないことを示す書類も必要です。

書類が増えるのが難点です。清算の申告で別表七(一)付表と実態貸借対照表がいります。申告ソフトによっては、この書類に対応していません。私の使っているソフトも対応していないので、資本金を厚くして、この手間が出てこない形にしました。

</Memo>

## 資本金を上げても、増える税金は1円もない

資本金を100万円にしても、設立や毎年の税金は1円も増えませんでした。どの税金も、境目はもっと上にあるからです。

| 税金 | 変わる境目 | 100万円にした結果 |
| :--- | :--- | :--- |
| 登録免許税（設立の登記でかかる税金） | 資本金の0.7%と6万円の大きいほう | 6万円のまま |
| 均等割 | 資本金などが1,000万円を超えると上がる | いちばん安い区分のまま |
| 消費税 | 資本金1,000万円以上だと、設立直後から納める | 最初の2年は原則納めなくてよいまま |

変わったのは、いつでも引き出せる財布が240万円から200万円に細ったことだけです。今の計画だと、会社の残高が200万円を超えるのは最初の1年くらい。困る場面はほとんどないと見ています。

## 想定外：貸付は200万円では終わらなかった

この記事を書いている今、計画は少し変わっています。[役員報酬を月4.5万円のまま据え置いた](/posts/design-1-houshu/)ので、会社のお金が早く減るんです。

最初の計画では、300万円がぎりぎり最後まで持つはずでした。今の計画では、4年目から毎年、足りない分を私が追加で貸します。最初の想定より、貸付は増えました。たたむまでに、追加は合計189.1万円の見込みです。資本金を厚くしておいたので、出口の法人税には響きません。

それでも、解散のときの差額は約57万円のままです。追加で貸した分は、あきらめる額と赤字が同じだけ増えるので、式の答えは変わりません。貸付が増えても、出口の法人税は心配いりません。

<Caution>

追加の貸付は、最初の200万円と同じ「役員借入金」として帳簿につけます。別の科目にすると、あきらめる対象から外れてしまい、上の式が成り立たなくなることがあります。

</Caution>

## で、あなたはどう分ける？

分け方は、会社をいつまで続けるか、何に使うかで変わります。

- 解散する時期を決めている人：均等割の年額に、続ける年数を掛けます。それより多めに資本金を置くと、たたむときの法人税を防げます
- 売上が立ち、黒字になる見込みの人：上の式は「毎年赤字」が前提なので、当てはまりません。資本金は、銀行の口座開設や取引先からの見え方も含めて決めることになります
- 途中で個人に戻したいお金が多い人：資本金は解散まで戻せないので、貸付の割合を多めにするほうが動かしやすいです
- 家族を出資者に入れる予定の人：貸したお金をあきらめると、ほかの出資者の持ち分の価値が上がります。贈与とみなされることがあります。私は出資者が自分1人なので、この問題は起きません

### 自分の数字は、3つで出せます

1. 「本店を置く自治体名　法人住民税　均等割」で検索し、資本金1,000万円以下のいちばん安い区分の年額を見る
2. それに、会社を続ける年数を掛ける
3. 資本金からそれを引く。プラスなら、その額が値上げや想定外への備えになります。マイナスなら、資本金を増やすか、貸付の一部を資本金に回します
