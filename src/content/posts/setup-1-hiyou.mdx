合同会社の設立にかかったお金は、68,590円でした。司法書士には頼まず、自分で手続きをしています。この記事では、その内訳と、設立のあと毎年かかるお金を、使ったサービスごとに全部書きます。

先に結論を言うと、設立費用で悩む時間は短くて大丈夫です。6万円が税金で、削れるところがほとんどありません。差がつくのは、設立のあとに毎年払うほうでした。そちらは後半に書きます。

## 設立の日までに払ったのは、これだけ

| 項目 | 金額 |
| :--- | ---: |
| 登録免許税（会社を登記するときに法務局へ納める税金） | 60,000円 |
| 設立サービスの利用料（電子定款の分） | 5,500円 |
| 法人の印鑑3本セットと表札（ネットの店で） | 3,090円 |
| **合計** | **68,590円** |

登記は、会社の名前や住所を法務局に登録する手続きです。申請した日が、会社の設立日になります。

図にすると、登録免許税だけが飛び抜けています。全体の9割近くです。

合同会社の登録免許税は、資本金（会社に最初に入れるお金）の0.7%と6万円の、大きいほうです。私の資本金は100万円なので、0.7%は7,000円。最低額の6万円になりました。

手続きは、弥生の会社設立サービスを使いました。流れは3つです。

1. 画面の案内に沿って、会社の名前や事業の目的などを入力する
2. 定款（会社のルールを書いた書類）の作成、資本金の払い込み、登記の申請をする
3. 設立が終わったら、税務署や年金事務所への届出を出す

2と3は、オンラインで進められます。合同会社は、株式会社で必要な定款の認証（公証人の確認）がありません。私は、定款から申請まで、このサービスの中で一気に済ませました。

登録と書類の作成は0円です。お金がかかるのは、電子定款の作成か、オンライン申請のシステムを使うときだけ。税込みで5,500円でした。

### 削れたのは定款の印紙代

定款を紙で作ると、収入印紙（税金を納めるために貼る切手のようなもの）が4万円かかります。電子定款は、定款を紙ではなくPDFのファイルで作ったものです。ファイルは印紙を貼る「文書」に入らないので、印紙が要りません。

私が払ったのは設立サービスの5,500円だけなので、差し引き34,500円が浮きました。設立費用の中で、自分の選び方で減らせたのはここだけです。

1つだけ、まぎらわしい点があります。合同会社に定款の認証が要らないことと、印紙が要らないことは、別の話です。合同会社でも、紙で作れば4万円かかります。

### 印鑑は見積もりよりずっと安かった

当初の資金計画では、印鑑などに1.5万円を見ていました。実際は、印鑑3本セットが2,220円です。高い素材を選ばなければ、このくらいで買えます。

印鑑を押す場面は、登記の書類と、相手のいる契約書だけにしました。社内の書類には押しません。使うのが年に数回なら、見た目にお金をかける理由がないな、と割り切りました。

### 登録免許税を半分にする手は、使わなかった

自治体の創業支援（起業する人向けの講座）を受けると、登録免許税が半額の3万円になります。私は受けませんでした。受講に1か月以上かかって設立が遅れるわりに、得になるのは1〜2万円だったからです。

ここはけっこう迷いました。くわしい計算は、[1年目・第1回の収支](/posts/monthly-y1-01/)に書いています。

## 毎年かかるお金は、ここで差がついた

設立が終わると、会社を続けるためのお金が毎年出ていきます。役員報酬（自分への給料）と社会保険料を除くと、次のとおりです。

| 項目 | 1年目 | 2年目〜 |
| :--- | ---: | ---: |
| 法人住民税の均等割（赤字でもかかる税金） | 70,000円 | 70,000円 |
| 全力会計（帳簿づけ・決算書） | 0円 | 11,880円 |
| 全力法人税（法人税の申告書） | 21,582円 | 11,000円 |
| フリーウェイ給与計算（給与計算・年末調整） | 0円 | 0円 |
| **合計** | **91,582円** | **92,880円** |

金額は税込みです。全力会計は初年度が無料で、2年目から年11,880円。全力法人税は初年度が21,582円で、続けて使う2年目からは年11,000円です。会計と申告のソフトを合わせると、1年目が約2.2万円、2年目からは約2.3万円になります。

私はこのほかに、AIツールとクラウドに年約5.2万円を払っています。月に約4,300円です。これは会社に必須のものではなく、仕事の中身によります。使わない人は0円です。

<Memo title="体験メモ">

会計ソフトは、正直いちばん悩みました。会計ソフトだけでは法人税の申告書が作れないことは、最初から知っていたんです。悩んだのは、その先でした。

会計はどのソフトにするか。申告は別のソフトを足すのか、自分で作るのか。組み合わせと方法がいくつもあって、なかなか決まりませんでした。名前をよく聞く freee やマネーフォワードは、私が調べた時点で年3〜5万円です。

</Memo>

会社は年に1回、決算書をもとに法人税の申告書を作って、税務署に出します。帳簿をつけるソフトと、申告書を作るソフトは、別の商品になっていることが多いんです。

会計と申告を大手のソフトでそろえる組み合わせも見積もりました。私が調べた時点で、年約7.2万円です。全力会計と全力法人税の組み合わせは、年約2.3万円でした。

差は年約4.9万円。私は法人を6年でたたむ計画なので、合計で約29万円になります。6年の理由は[解散の記事](/posts/concept-1-kaisan/)に書きました。

設立費用は約6.9万円ですから、**設立費用の4倍以上の差が、ソフト選びだけでつく**わけです。この数字を見て、組み合わせを決めました。

給与計算は、フリーウェイ給与計算の無料版です。5人までなら、期限なしで0円で使えます。役員1人の給与明細、年末調整（1年分の税金の精算）、役所に出す書類まで、これで足りました。

## 安い組み合わせで、気をつけること

安い組み合わせには、やはり理由があります。選ぶ前に知っておきたいことを、2つ書きます。

1つめは、申告ソフトで作れない書類があることです。具体的には「別表6」です。法人が配当や利息を受け取ると、先に税金が引かれます。それを取り戻すための書類が別表6で、全力法人税の対応書類の一覧に入っていません。

freee の申告ソフトは、対応する書類の一覧に別表6が載っています。ただ、どの料金プランで使えるかまでは、私は確かめていません。

正直、別表6を書くのも、引かれた税金を返してもらう手続きも、面倒だなと思いました。だったら、そもそも税金が先に引かれない形にすればいい。そう考えて、投資のやり方のほうを合わせました。

法人で買うのは、分配金が出ない投資信託にします。売るときは、SBI証券の「買取」という方法を選びます。法人の口座では、買取にすると、売ったときに税金が先に引かれません。別表6が要る場面を、はじめから作らないわけです。

2つめは、無料期間の数え方です。全力会計の「初年度無料」は、申し込んだ日ではなく、初期設定を終えた日から1年です。帳簿をつけ始める前に設定すると、使わない月のぶんだけ無料期間が減ります。

## 銀行とカード：事業と投資で口座を分けた

法人の口座は2つです。メインが三井住友銀行のTrunk（法人向けのネット口座）で、主に給与と売上に使います。サブがドコモSMTBネット銀行で、主にSBI証券とのやりとりに使います。

カードは、三井住友カード ビジネスオーナーズという法人カードです。年会費は無料で、引き落としはTrunkにしています。

SBI証券の側では、出金先の口座も、入金に使う口座も、三井住友銀行にしました。ドコモSMTBネット銀行は、SBIハイブリッド預金に設定しています。銀行の預金を、そのまま証券口座の買付に使える仕組みです。

この形にして、よかったことが2つあります。1つは、事業のお金と投資のお金が混ざらないこと。帳簿をつけるときに、どの入出金が何なのかで迷いません。

もう1つは、SBI証券を通せば、2つの銀行の間でお金を手数料なしで動かせることです。ドコモSMTBネット銀行から証券口座へ入れて、証券口座から三井住友銀行へ出す。これで振込手数料がかかりません。

### 役員報酬の振り込み方は、銀行でちがう

毎月の役員報酬は、Trunkの「給与振込」で、月に1回振り込んでいます。受け取る個人の口座も同じ銀行にしたので、振込手数料はかかっていません。他の銀行あてだと手数料がかかるのは、どの銀行でも同じです。

ドコモSMTBネット銀行には、給与振込のメニューがありません。こちらから払うなら、ふつうの振込になります。日付を決めて予約しておくことはできます。

### 社会保険料の口座振替で、少し足止めされた

社会保険料を口座からの自動引き落としにするには、申出書を年金事務所に出します。案内では、この申出書に銀行の確認印をもらうことになっています。ネット銀行なら、確認印は要りません。

<Memo title="体験メモ">

困ったのは、Trunkがどちらの扱いなのか、はっきりしなかったことです。銀行のサポートに聞くと、法人を扱う支店で確認印を押してもらえる、という答えでした。

ところが、最寄りの支店の法人窓口をネットで予約しようとしたら、空きは2週間後。そこで、だめもとで年金事務所に直接持っていきました。確認印なしで、そのまま受け付けてもらえました。

今のところ、年金事務所から連絡は来ていません。問題はなさそうです。

</Memo>

私の場合の話なので、同じ扱いになるとは限りません。銀行の予約が先になりそうなら、年金事務所に先に聞いてみる手はあると思います。口座振替が始まるまでの社会保険料は、届いた納付書で払います。

### 口座ができる前に払ったお金の扱い

設立費用の68,590円は、会社の口座ができる前の支払いです。個人のお金で先に払いました。帳簿では「創立費」（会社を作るためにかかった費用）として処理しています。

会社から現金で返してもらってはいません。会社の口座には、資本金の100万円から、先に払った創立費のぶんを引いた金額を入金しました。これで帳簿と口座の残高が合います。

## あなたの場合はどうか

私と条件がちがう人は、金額も選び方も変わります。正直、ここは私の経験だけでは言い切れません。それでも、調べていて「自分がこの立場なら迷うな」と思ったところを4つ挙げます。

- 株式会社を作る人：登録免許税の最低額が15万円で、定款を公証人に確認してもらう手数料もかかります。創業支援で半額になる効果が大きいので、受ける価値は合同会社より上がると思います
- 借入を考えている人：創業支援には、創業のための融資を受けやすくなる効果もあります。借りる予定があるなら、私なら設立が遅れても受けます。減る税金の3万円より、融資のほうがずっと大きいので
- 法人で配当や分配金を受け取る人：安い申告ソフトでは作れない書類が出てきます。ソフトを決める前に、対応書類の一覧を見ておくと安心です
- 従業員を雇う予定の人：給与ソフトの無料版には人数の上限があります。増える見込みなら、最初から有料版の料金で比べたほうが安心です

### 自分の数字で確かめる方法

1. 登録免許税を出す。合同会社は「資本金×0.7%」と「6万円」の大きいほうです。資本金が約857万円までなら6万円です
2. 定款を紙にするか電子にするかを決める。紙なら4万円を足します。電子なら、設立サービスの料金ページに出ている金額を足します。「電子定款」や「システム利用料」という名前で載っています
3. 会計ソフトを、申告のソフトと合わせた年額で比べる。会計だけの料金で比べると、私のようにあとで驚きます
4. 無料期間があるソフトは、「いつから数えるか」を公式サイトで確かめる。数え始めが早いと、使わないうちに終わります
5. 3で選んだ「会計＋申告」の年額に、会社を続ける年数を掛ける。設立費用と比べると、どこに時間を使うべきかが見えます

私の場合、金額がいちばん動いたのは3のソフトの比較でした。ここだけは、時間をかける価値があると思います。

まとめると、こうです。設立のときは「登録免許税＋定款（紙なら4万円、電子ならその料金）＋印鑑」。

毎年は「均等割＋会計＋申告＋給与ソフト」。仕事で使う道具があれば、それも足します。この2つを足せば、あなたの場合の金額が出ます。

## 次は、法人を作らない場合との比較

設立に約6.9万円、毎年の税金とソフトに約9.3万円。ここに役員報酬と社会保険料が乗ります。全部を足した年間の支出は、[1年目・第1回の収支](/posts/monthly-y1-01/)にまとめました。

これだけ払っても、法人を作らないより得なのか。いちばん気になるのは、そこですよね。次の記事では、あなたの数字を入れて比べられる計算機を用意します。私の場合の答えは、[前日譚の最終回](/posts/prequel-5-hojin/)に先に書いてあります。
