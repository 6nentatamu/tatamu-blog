マイクロ法人の銀行口座は、設立の直後に3行へ同時に申し込み、3行とも開設できました。使っているのは2つです。事業用が三井住友銀行の法人向けの口座であるTrunk、投資用がドコモSMTBネット銀行です。GMOあおぞらネット銀行の口座は、予備として残しています。

どの銀行にするか迷う人は、先に、使う証券会社が対応している銀行を確かめ、そこから1つ決めると進めやすいです。ほかの選択肢として、ラクスルバンクとフィンサーバンクも紹介します。

## 銀行は、1行ずつ待たずに同時に申し込んだ

法人の銀行口座は、1行ずつ申し込むと、審査を待つ時間がそのまま積み上がります。1行目の結果を見てから2行目に進めば、運用を始める日がそのぶん遅れます。

遅れると困る理由が、証券口座です。法人の証券口座は、入出金に法人名義の銀行口座を使う前提で、申込にも入出金用の銀行口座を書く欄があります。つまり、銀行が開かないと、証券口座の申込も運用も始められません。この順番の話は[証券口座の記事](/posts/setup-5-shoken/)に詳しく書きました。

そこで、銀行は同時に進めるしかないと決めて、3行に申し込みました。結果として3行とも開設できました。

## 申込から開設まで、1週間と約2週間

申込は、設立から数日のうちに済ませました。ドコモSMTBネット銀行とGMOあおぞらネット銀行は、申込画面に入力して送る形です。Trunkは、申込のあとにWeb面談がありました。事前に、10分ほどと聞いていました。

開いた順番は、次のとおりです。

- 設立から約1週間：TrunkとドコモSMTBネット銀行が開設
- 設立から約2週間まで：GMOあおぞらネット銀行が開設

Trunkの公式の案内は最短即日ですが、私は設立から約1週間でした。

銀行の口座が開いた日に、SBI証券の申込書を取り寄せました。銀行が先に開いたぶん、証券口座の申込に早く進めたことになります。

審査で気になる点として、電話番号と本店と書類があります。電話番号は、3行とも携帯の番号で通りました。固定電話は要りませんでした。登記簿謄本の原本は、銀行3行では要らず、出したのは証券口座だけです。

本店は自宅です。自宅にした決め手は、法人口座と証券口座の審査で、余計な説明をしたくなかったことでした。その経緯は[本店の記事](/posts/setup-4-honten/)にあります。結果として、銀行も証券も問題なく開設できました。

## 2つの口座の使い分け

使っている2つの口座は、お金の種類で分けました。

| 口座 | 使い道 |
| :--- | :--- |
| 事業用：Trunk | 売上の入金、役員報酬の給与振込、社会保険料の口座振替、法人カードの引き落とし |
| 投資用：ドコモSMTBネット銀行 | SBIハイブリッド預金でSBI証券とつなぐ、私が会社に貸す役員借入金の受け皿 |

SBIハイブリッド預金は、銀行の預金を、そのまま証券口座の買付に使える仕組みです。SBI証券から出金するときの受け取り先は、Trunkにしました。

分け方は次のとおりです。投資は、ドコモSMTBネット銀行とSBI証券をつないで管理します。事業の支払いは、Trunkと三井住友カードで済ませます。三井住友カードは、Trunkと一緒に申し込みました。

最初は、ドコモSMTBネット銀行1つに、売上も給与も社会保険料も証券もまとめる案でした。最後は、投資と事業で口座を分けることにしました。

Trunkには50万円を残しておき、半年ごとに、ドコモSMTBネット銀行から50万円に戻るように補充します。足りなくなりそうなときは、その都度戻します。

GMOあおぞらネット銀行の口座は、予備です。口座維持の手数料はかからないので、残高ゼロのまま、解約せずに残しています。

役員報酬の振込や、社会保険料の口座振替の申出書の出し方は、[設立費用の記事](/posts/setup-1-hiyou/)に書きました。

## 自分の口座の決め方

私が使い分けを決めた観点は、2つです。自分の場合に当てはめるときの材料にしてください。

1つめは、証券口座とどうつなぐかです。即時入金は、銀行の口座から証券口座へ、すぐ入金できる仕組みです。私が調べた時点では、SBI証券の法人口座で対応する銀行は、ドコモSMTBネット銀行とPayPay銀行だけでした。投資用の口座は、使う証券会社が対応している銀行から選ぶと、入金の手間が減ります。

2つめは、給与や社会保険料をどの口座に集めるかです。銀行ごとに、給与振込のメニューがあるかを見ます。社会保険料の口座振替と、法人カードの引き落とし先にできるかも確かめます。私は、この3つをTrunkにまとめました。給与は、Trunkから三井住友銀行の私の個人口座へ振り込むので、同じ銀行宛で手数料がかかりません。

私の組み合わせが合うのは、SBI証券を使う人と、給与と社会保険料とカードの引き落としを1つの口座にまとめたい人です。

## 各行の条件を並べる

私が申し込んだ3行について、公式サイトで確かめた条件です。

| 銀行 | 口座維持の手数料 | 他行宛の振込手数料 |
| :--- | :--- | :--- |
| Trunk | 月額利用料0円 | 1回145円を引き落とし、45円は後日返金で実質100円。返金に条件あり |
| ドコモSMTBネット銀行 | 月額基本料金0円 | 通常の振込は100円 |
| GMOあおぞらネット銀行 | 0円 | 100円 |

同じ銀行宛の振込は、Trunkの三井住友銀行宛とドコモSMTBネット銀行宛が0円です。申込に要る書類は、銀行で分かれます。

- Trunk：法人の実在性と事業内容を確認できる書類を、契約書、請求書、事業計画書などから出します。フォームにアップロードして、本人確認を受けます。私の場合は、申込のあとにWeb面談がありました。来店は要りません。公式の案内では、申込はスマホで最短20分、開設は最短即日です。合同会社は、実質的支配者の確認で定款が要ることがあります。代表して業務執行する個人だけなら、要りません
- GMOあおぞらネット銀行：取引責任者の本人確認書類と、事業内容を確認できる書類です。取引責任者は、口座でのすべての取引を行う権限を持つ担当者です。代表者が取引責任者なら、履歴事項全部証明書、印鑑証明書、定款は要りません。事業内容の書類は、契約書、ホームページ、請求書、会社案内、事業計画書などから選べます

表の数字は、公式サイトの日付によって変わることがあります。申し込む前に、各行の手数料ページで確かめるのが確実です。

## ほかの選択肢：ラクスルバンクとフィンサーバンク

私が申し込んだのは上の3行ですが、法人口座はほかにも選べます。申込の手間や時間を減らしたい人に向く2つを、公式の案内から紹介します。

### ラクスルバンク

<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEIPF+CI3Q42+5VV8+5YRHE">ラクスルバンク</AffLink>の口座は、GMOあおぞらネット銀行の法人口座です。ラクスルバンク株式会社が、同行の銀行代理業者として提供しています。銀行代理業者は、銀行に代わって口座の申込を受け付ける会社です。

すすめる理由は2つあります。

- 申込と本人確認が、オンラインで終わります
- 最短で申込の当日に開設できると案内されています。最短当日の開設には、GMOあおぞらネット銀行が指定する条件があります

口座はGMOあおぞらネット銀行のものなので、同行の審査があります。

他行宛の振込手数料は119円です。

向いているのは、窓口に行かずに、ネットだけで法人口座を作りたい人です。

### フィンサーバンク

<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEIPF+CJALBM+5ULY+5YRHE">フィンサーバンク</AffLink>は、口座が北國銀行のものであるオンラインバンクです。フィンサーバンクを運営するf9kは、銀行ではなく金融サービス仲介業者です。金融サービス仲介業者は、銀行と利用者を仲立ちする会社です。

すすめる理由は3つあります。

- 申込はオンラインで、最短15分と案内されています
- 登記簿謄本と定款が要りません
- 月額無料のフリープランがあります

料金は、税抜の月額で3つのプランがあります。振込手数料は、都度振込と総合振込の値です。給与振込は別の料金です。

| プラン | 月額 | 他行宛の振込 | 同行宛の振込 |
| :--- | :--- | :--- | :--- |
| フリー | 無料 | 110円 | 13円 |
| スタンダード | 2,980円 | 90円 | 13円 |
| プロ | 7,980円 | 90円 | 13円 |

向いているのは、謄本などの書類をそろえずに、短い時間で申し込みたい人です。他行への振込が多い人は、月額と1件あたりの手数料を、自分の振込の件数で計算して選べます。
