会社の書類は、置き場所を3つに分けました。取引先と電子でやりとりした請求書や領収書は、会計ソフトの電子帳簿へ入れます。私が使っている全力会計の、全力電子帳簿というサービスです。自分で作った書類は、Googleドライブです。紙でもらった領収書は、紙のまま残しています。

請求書や領収書のように、取引の裏づけになる書類を、証憑といいます。迷ったときの決め方は、「取引先と電子でやりとりしたものか、自分で作って手元に置くものか」です。これで、同じものを2か所で管理することがなくなりました。

もう一つ、作る前に知っておけばよかったことがあります。合同会社の帳簿は、10年残します。たたんだあとも10年です。私の会社は6年でたたむ前提なので、たたんだあとの10年も、帳簿を持ち続けることになります。

## 置き場所は「取引先とやりとりしたか」で決める

最初に決めたのは、この線引きです。

| 何か | どこへ置くか |
| :--- | :--- |
| 取引先と電子でやりとりした請求書・領収書。受け取ったものも、送ったものも | 全力電子帳簿 |
| 自分で作って手元に置く書類、届出の控え、規程 | Googleドライブ |
| 紙でもらった領収書 | 紙のまま |

取引先と電子でやりとりしたデータは、電子取引データといいます。法律で、残し方が決まっています。自分で作って手元に置く書類は、なくさず探しやすい形にしておくのが中心です。性格の違うものを同じ場所に入れると、どちらのルールで残すのかがあいまいになります。なので、最初に分けてしまいました。

銀行とカードの明細も電子取引データですが、置き場所は全力会計です。連携で取り込んでいて、保存の要件はソフトの側で満たせます。くわしくは、[会計ソフトの記事](/posts/setup-2-kaikei/)に書きました。

もう1つ例外があります。電子契約のサービスで結んだ契約書も、電子取引データです。私は、会社にお金を貸すときの契約書を電子契約で結びました。貸した理由と形は、[資本金と貸付の記事](/posts/design-2-shihonkin/)にあります。この契約書は何度も見返すので、電子のまま、Googleドライブの契約書のフォルダに置いています。Googleドライブに置いても電子取引データなので、次の節の残し方のルールに含めています。

## 電子帳簿保存法で、やることはほぼ1つでした

電子帳簿保存法は、会社や個人事業主が、帳簿や領収書を電子で残すときのルールを決めた法律です。名前だけ聞くと大がかりに見えます。ところが、小さな会社に当てはめると、やることはかなり絞れます。

中心は、メールやWebでやりとりした請求書や領収書を、電子のまま残すことです。紙に印刷して残す形は、原則として使えません。

残すときは、あとから書き換えられない形にしておきます。方法は主に4つあります。

- 取引先が、データに時刻の証明を付けて送ってくる。この時刻の証明を、タイムスタンプといいます
- 受け取った側が、タイムスタンプを付ける
- 直した履歴が残るか、直せないソフトに入れる
- 書き換えを防ぐ社内のルールを、事務処理規程として備え、そのとおりに運用する

私は、事務処理規程を備える形にしました。備えるだけでなく、規程のとおりに残していることが要件です。

検索できるように整える要件は、私の会社にはかかりません。前々事業年度、つまり2つ前の事業年度の売上高が5,000万円以下なら、いりません。税務署に頼まれたら、データを出して見せられることが条件です。売上高は、決算書の損益計算書の、いちばん上の数字で見ます。設立して1年目と2年目は、前々事業年度がないので、この要件はいらないと、国税庁の一問一答で示されています。私の会社の売上は、この基準を大きく下回る計画です。

結局、やることは「電子で来たものを、電子のまま、書き換えられない形で、なくさずに置いておく」まで縮みました。

## 証憑をGoogleドライブに置く案は捨てました

最初は、証憑もGoogleドライブで管理するつもりでした。収入の明細、支出の領収書、紙のスキャンと、フォルダまで作っていたんです。

ところが、全力会計の利用者なら、全力電子帳簿の月100ファイルまでのプランを0円で使えます。私の証憑は月10件ほどなので、十分です。

決め手は、仕訳と証憑がひもづくことでした。仕訳は、お金の出入りを帳簿に書いた記録です。全力電子帳簿を通して仕訳を登録すると、証憑が全力会計の仕訳に添付されます。Googleドライブだと、ある仕訳の裏づけを見たいとき、別のフォルダをファイル名で探すことになります。

作っていた証憑用のフォルダは、中身が空のうちに消しました。

## 紙の領収書は、スキャンせずに残す

紙でもらった領収書は、紙のまま残しています。スキャンして原本を捨てる形は、スキャナ保存という別の制度です。守る要件が増えます。

スキャンを手元に置くのはかまいません。ただ、それは探しやすくするための写しで、原本ではありません。

## 帳簿は10年残し、たたんだあとも残る

合同会社には、会社法で、帳簿と事業の大事な資料を10年残す義務があります。税法でも、法人には帳簿を原則7年残す義務があります。青色申告で欠損金、つまり赤字が出た事業年度は10年です。青色申告は、帳簿をきちんとつける代わりに、税の優遇を受けられる申告のしかたです。どちらで見ても、10年残しておけば足ります。

ここで想定外がありました。法人をたたむ計画を作ったとき、私が見ていたのは、登記の費用と公告の費用だけでした。公告は、たたむことを官報という国の広報紙で知らせる手続きです。帳簿をどこに置くかが、すっぽり抜けていたんです。

たたんだあとも、会社法では、清算が終わった登記のときから10年、帳簿を残します。残すのは、原則として清算人です。清算人は、会社をたたむ手続きを進める人で、ひとりの会社なら私です。一方で、法人がなくなれば、会社名義で契約しているサービスも終わります。

そこで、たたむ前に次の3つを書き出して、私個人の手元に移すことにしました。

| 何を | どうやって |
| :--- | :--- |
| 全力電子帳簿の証憑 | バックアップの機能で、一覧と証憑のファイル本体をダウンロードする |
| 全力会計の仕訳 | 仕訳日記帳をエクスポートする。弥生の形式でも出せる |
| Googleドライブの書類 | Google Takeout（Googleのデータをまとめて書き出す機能）か、手でダウンロードする |

全力電子帳簿は、退会の前にバックアップを取れば、証憑のファイル本体を手元に残せます。書き出すのは退会の前、と決めています。たたむときの1回に頼ると、その1回で失敗したら終わりです。なので、毎年の決算のあとにも書き出して、なくしても1年分で済むようにするつもりです。

## Googleドライブは無料のまま、バックアップを2重に

自分で作った書類は、無料のGoogleアカウントのドライブに置いています。会社向けの有料版にすると、毎月の料金がかかります。独自ドメインのメールがなくても困らない作りにしていたので、無料のままにしました。

無料のアカウントで怖いのは、アカウントが止まったら全部なくなることです。そこで、バックアップを2重にしました。

| 何で | どれくらい | 何から守るか |
| :--- | :--- | :--- |
| パソコン版Googleドライブのミラーリング | いつも | アカウントが止まったとき |
| Google Takeout の定期エクスポート | 2か月ごとに1年間 | 消してしまったときや、同期の事故 |

ミラーリングは、パソコンにもファイルの実体を置く設定です。ストリーミングにすると、パソコンに実体が残りません。ここは選び間違えると意味がなくなるところです。

実際に設定してみて、2つ想定外がありました。1つは、Googleドキュメントとスプレッドシートは、私の環境では、ミラーリングでもパソコンに中身が来なかったことです。小さなショートカットのファイルになるだけでした。これらを守れるのは、Takeoutの書き出しだけです。

もう1つは、Takeoutの書き出し先です。書き出し先は、Googleドライブのほか、OneDriveやDropboxなども選べます。私はGoogleドライブを選んだので、書き出したファイルがGoogleドライブの中のフォルダに入りました。それだとGoogleの外に残りません。月に1回の整理のときに、書き出したファイルを別の場所へ手でコピーしています。Takeoutの予約は1年で切れるので、毎年かけ直します。手作業は、それくらいです。

## あなたはどこに置くか

置き場所は、使っている会計ソフトで変わります。次のように考えてみてください。

- 会計ソフトに証憑を保存する機能がある人：そこへ入れると、仕訳と証憑がひもづきます。探す手間がいちばん少ない形です
- これから会計ソフトを選ぶ人：証憑を電子帳簿保存法に合わせて残せる機能があるかを、選ぶ条件に入れておくと楽です
- 申告を税理士に頼む人：証憑の受け渡しの形は、税理士と先に決めておくと、二度手間になりません
- 紙の領収書が多い人：紙のまま残すか、スキャナ保存の要件を満たすかを、最初に決めておきます
