会計ソフトを選ぶとき、最初に見たのは機能の多さでも、画面の見やすさでもありませんでした。「法人税の申告書まで、自分で作れるか」です。

会計ソフトの多くは、決算書を作るところまでです。法人税の申告書は、別のソフトを使うか、税理士に頼みます。私は申告まで自分でやる計画なので、ここが一番の条件でした。税理士に頼む人は、決算書まで作れるソフトで足ります。

## 会計ソフトと申告ソフトは、別ものです

法人の1年の終わりには、2つの書類を作ります。

<Steps items={[{ title: '決算書', note: '1年の取引をまとめた損益計算書と貸借対照表。会計ソフトが作る' }, { title: '法人税の申告書', note: '決算書をもとに、税金を計算する書類。会計ソフトだけでは作れないことが多い' }]} />

税理士に頼むなら、会計ソフトは決算書まで作れれば足ります。自分で申告までするなら、申告書を作れるソフトがもう1つ要ります。2つのソフトの間で、決算書の数字を移す手間も出てきます。

## 私の構成：会計と申告を同じ会社でそろえた

選んだのは、次の3つです。

| 役割 | 使っているソフト | 費用 |
| :--- | :--- | :--- |
| 会計（決算書まで） | 全力会計 | 1年無料、そのあと年払いで月900円＋税 |
| 法人税の申告書 | 全力法人税 | 申告書を出力する年度ごとに支払い |
| 給与計算 | フリーウェイ給与計算 | 無料版 |

全力会計の決算書は、全力法人税に連携作業なしで渡ります。数字を打ち直さずに申告書へ進めるのが、この組み合わせにした理由です。会計と申告を合わせたソフト代は、私の見積もりで年2万円台です。

別々の会社でそろえる形は、決算書を移す手間と、2つの契約の費用がかかります。使い慣れたソフトがある人に向きます。全力会計は1年無料なので、合わなければ1年以内にほかへ移ればいい、とも考えました。

<Point>

全力会計の無料期間は、暦年ではなく「初期設定を終えた日から1年」です。法人口座ができる前に設定すると、使わない間に無料期間が減っていきます。口座ができて、記帳を始められる状態になってから設定するのがおすすめです。

</Point>

## 想定外：申告ソフトにも、対応していない書類があった

調べていくと、想定外のことが分かりました。全力法人税は、投資信託の分配金などで引かれた所得税を取り戻すための書類に対応していませんでした。この書類は別表六(一)といいます。

私の会社は、会社のお金を投資信託で運用する計画です。分配金を受け取ると、この書類が要ります。そこで、分配金が出ない投資信託だけを持つ方針にしました。ソフトを変えるより、書類が要らない形にするほうが安かったからです。

会社で運用をする予定の人は、申告ソフトが対応している書類の一覧を、先に見ておくと安心です。

## 給与計算は、無料版で足りた

マイクロ法人でも、役員報酬を払うなら給与計算がいります。源泉徴収票や年末調整もあります。私はフリーウェイ給与計算の無料版を使っています。人数が少ないうちは、無料の範囲で足りています。

無料版でも、年末調整、源泉徴収票、給与支払報告書、法定調書合計表まで作れます。e-Tax 用と eLTAX 用のファイルも、無料で出力できます。その年の分の出力の機能は、年末から1月ごろに追加されるので、公式のお知らせで確かめます。eLTAX 用のファイルは、eLTAX の PCdesk のダウンロード版で取り込みます。

## ソフトの外でやることが2つある

3つのソフトでそろわないものが2つあります。社会保険の届出と、源泉所得税の納付です。

社会保険の届出は、日本年金機構の「届書作成プログラム」か e-Gov で、無料で出せます。6月1日より前から社会保険に入っていれば、役員1人の会社でも、毎年7月1日〜10日に算定基礎届を出します。4〜6月の報酬をもとに、9月からの保険料を決め直す届出です。

源泉所得税は、e-Tax で納めます。役員報酬が少ないと、引く所得税が0円の月もあります。国税庁の案内では、0円でも、納付書にあたる「所得税徴収高計算書」を出します。私も、0円の計算書を e-Tax で出しました。

給与を払う人が常に10人未満の会社は、「納期の特例」を税務署に申請できます。承認されると、源泉所得税は半年分ずつ、年2回にまとめられます。1〜6月分は7月10日まで、7〜12月分は翌年1月20日までです。申請した月の翌月に払う給与の分から使えるので、それまでは毎月、翌月10日までに納めます。

## 1年の経理は、この順で回る

私の会社の1年の予定は、次のとおりです。週1回の仕訳と、毎月の給与のほかは、決まった時期に1回ずつです。

| 時期 | やること | 使うもの |
| :--- | :--- | :--- |
| 週1回 | 仕訳と、領収書の保存 | 全力会計 |
| 毎月 | 役員報酬の計算と振込 | フリーウェイ給与計算 |
| 7月1日〜10日 | 社会保険の算定基礎届 | 届書作成プログラム |
| 7月10日・1月20日 | 源泉所得税の納付（納期の特例） | e-Tax |
| 12月 | 年末調整 | フリーウェイ給与計算 |
| 1月31日まで | 給与支払報告書を、役員が住む市区町村へ出す。源泉徴収票は役員本人に渡す | フリーウェイ給与計算から eLTAX |
| 事業年度が終わった翌日から2か月以内 | 法人税・法人住民税・事業税の申告 | 全力会計から全力法人税 |

給与支払報告書の出し先は、会社の本店がある市区町村ではなく、役員が1月1日に住んでいる市区町村です。本店を自宅にした会社なら同じですが、別にした会社は気をつけたいところです。

源泉徴収票を税務署にも出すのは、役員の給与が年150万円を超えるときです。さらに2027年1月からは、市区町村に給与支払報告書を出せば足ります。源泉徴収票も税務署に出したものとみなされます。

銀行とカードの明細は、全力会計に連携で取り込んでいます。全力会計の案内では、連携で取り込んだ明細は電子帳簿保存法の要件を満たします。別にダウンロードして残さなくてよいとされています。売上が5,000万円以下の会社の場合です。全力会計の連携先は銀行やカードなどで、証券口座は一覧にありません。証券は、売り買いした日だけ手で入力します。

## この構成が合う人

- 申告まで自分でやると決めている人：会計と申告を同じ会社でそろえると、数字を移す手間がなくなります
- 費用をできるだけ抑えたい人：1年無料のあいだに、決算まで回せるかを確かめられます
- 申告は税理士に頼む人：申告ソフトは要りません。会計ソフトは、頼む税理士が使っているものに合わせると、やりとりが楽です
- 給与計算や年末調整まで、1つのサービスにまとめたい人：会計・給与・年末調整などがセットになったサービスもあります。[マネーフォワード クラウドの紹介](/posts/setup-3-moneyforward/)に、どんな人に合うかをまとめました

銀行明細の取り込みを重視して、ほかの会計ソフトと比べたい人には、<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEMLQ+8SQMLU+35XE+6IP2Q">弥生会計 Next</AffLink>があります。0円の無料体験プランで、最大2か月試せます。体験中は決算書を作れないので、決算の前に有料プランへ切り替えます。年額は税抜34,800円からです。法人税の申告書は、連携する別のソフトで作る案内です。
