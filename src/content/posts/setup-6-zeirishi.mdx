マイクロ法人の決算と法人税の申告は、自分でやると決めました。使うのは会計ソフトと申告ソフトだけで、費用は私の見積もりで年2万円台です。

先に書いておくと、これは「誰でも自分でできる」という話ではありません。私が自分でやれると考えたのは、難しい申告が出ない形に、会社のお金の流れを最初から決めたからです。その形にできない人は、税理士に頼むほうが合います。どちらが合うかを、この記事で確かめられるようにしました。

## 自分でできると考えた理由

私は FP2級の勉強で、税金のしくみは学んでいます。とはいえ、法人の決算は初めてです。私が考えた作業の流れは、次のとおりです。

<Steps items={[{ title: '日ごろの帳簿付け', note: 'お金の出入りを、会計ソフトに記録する' }, { title: '決算書', note: '1年の記録をまとめた書類。会計ソフトが帳簿から作る' }, { title: '法人税の申告書', note: '決算書をもとに税金を計算する書類。申告ソフトに決算書を渡して作る' }]} />

日ごろの帳簿付けは、簿記3級ほどの知識で大丈夫だと思えました。簿記3級は、簿記の入門の資格です。会計ソフトで帳簿をつければ決算書ができて、決算書を申告ソフトに渡せば申告書ができます。ここまで分かって、これなら自分で回せる、と思えたんです。

ソフトの組み合わせは、[会計ソフトの記事](/posts/setup-2-kaikei/)に書きました。会計と申告を同じ会社でそろえ、決算書の数字を打ち直さずに申告書へ進める形です。

## 難しい申告は、最初から出ない形にした

自分でやれるかどうかは、知識より、会社のお金の流れで決まると考えました。なので、手間のかかる申告や書類が出る場面を、設計の段階で外しています。

| 決めたこと | 出なくなるもの |
| :--- | :--- |
| 消費税を納める側にならない規模にとどめる | 消費税の申告 |
| 登録しない | インボイス |
| 分配金が出ない投資信託だけを持ち、税金が先に引かれない売り方で売る | 分配金の書類 |
| 資本金を厚くした | たたむ年の書類 |

消費税は、会社が売上で預かった消費税から、仕入れなどで払った分を引いた差額を、国に納める税金です。

消費税を納めるかどうかは、2年前の課税売上高で決まります。課税売上高は、消費税のかかる売上のことです。これが1,000万円以下なら、その年は納めなくてよい扱いです。新しく作った会社には、2年前の売上がありません。なので資本金が1,000万円未満なら、設立から2期は原則として納めなくてよい扱いです。例外は、前の期の最初の6か月です。この6か月の課税売上高と、払った給与が、どちらも1,000万円を超えると、納める側になります。

インボイスは、国に登録した事業者だけが出せる請求書です。登録すると、消費税の申告が必要になります。私の会社は、消費税の申告もインボイスも必要ない形で続けます。

分配金も、手間が出る場面でした。会社が投資信託の分配金を受け取ると、所得税が先に引かれます。会社が払う法人税から、この所得税を差し引いてもらうには、別表6という書類が要ります。ところが、私の申告ソフトは、この書類に対応していませんでした。これは想定外でした。

ソフトを替えるより、書類が要らない形にするほうが、手間も費用も少なく済む。そう考えて、運用のほうを合わせました。ソフトの費用は[設立費用の記事](/posts/setup-1-hiyou/)に書いています。分配金が出ない投資信託だけを持ち、売るときは買取請求を選びます。買取請求は、証券会社に買い取ってもらう売り方です。SBI証券の法人口座では、買取請求なら、売ったときに税金が先に引かれません。こうすれば、投資信託については、別表6が要る場面を作らずに済みます。売り方の違いは[証券口座の記事](/posts/setup-5-shoken/)に書きました。

会社をたたむ年の申告も、同じ考え方です。私は会社にお金を貸していて、たたむときは、返してもらわないことにする計画です。返さなくてよくなった分は、会社のもうけとして扱われます。毎年の赤字で打ち消せれば、法人税はかかりません。

ただ、赤字でもかかる住民税の均等割は、この打ち消しに数えられません。私の会社の均等割は年7万円で、たたむまでの合計は約43万円です。そこで資本金を100万円にして、約57万円の余裕を残しました。計画どおりなら、たたむ年も法人税がかからず、手間のかかる書類も使わずに済む見込みです。決め方は[資本金の記事](/posts/design-2-shihonkin/)にあります。

## 税理士に頼むほうが合う人

私の形は、会社で扱うお金の流れが少ないから成り立っています。次のどれかにあてはまる人は、税理士に頼むほうが、時間もお金も読みやすくなります。

- 売上が大きくなりそうな人：消費税を納める側になると、消費税の申告が毎年加わります
- 取引先からインボイスを求められる人：登録すると、消費税の申告が必要になります
- 会社で配当や分配金を受け取る人：税金を取り戻すには、書類が毎年要ります
- 人を雇う予定の人：給与と社会保険の手続きが増えます
- 簿記に触れたことがなく、帳簿付けに時間をかけたくない人：ほかのことに時間を回せます

会社の維持費は、均等割7.0万円と、会計と申告のソフト2.6万円で、計画時の見積もりでは年約9.6万円です。自分でやる人も頼む人も、この維持費に何が乗るかを先に書き出しておくと、比べやすくなります。

## 会社を作る前に、相談する方法もある

そもそも法人にするかで迷っている段階なら、作る前に税理士に相談する方法があります。会社設立を扱う<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEMLQ+8QYBSI+5LH2+5YJRM">税理士法人経営サポートプラスアルファ</AffLink>は、法人化の相談を、初回1〜2時間ほど、何度でも無料で受けています。

相談では、個人のままの場合と法人にした場合の税金を、試算して比べてもらえます。事務所に行くほか、Zoom でも受けられます。依頼するかどうかは、相談のあとで決められます。

私は、個人と法人の負担を自分の数字で比べてから決めました。比べ方は[計算機の記事](/posts/concept-2-keisanki/)にあります。税理士に一度見てもらってから決めたい人や、自分の数字に確信を持って決めたい人には、この相談が向いています。

## 頼む税理士の探し方

どこに頼めばいいか分からない人は、紹介を使う方法があります。<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEHXA+BT3IPE+35XE+I3SIA">弥生の税理士紹介サービス</AffLink>は、全国にある弥生のパートナー会計事務所から、相談先を紹介してもらえるしくみです。紹介は無料で、初回の相談も無料です。会社を作る前の人も、作ったあとで決算に不安がある人も申し込めます。

流れは、申し込むと弥生が事務所を紹介し、事務所から提案を受けて、納得したら契約する形です。合わなければ、別の事務所を紹介してもらえます。

## マイクロ法人向けのパッケージもある

マイクロ法人向けに料金をまとめた事務所もあります。<AffLink href="https://px.a8.net/svt/ejp?a8mat=4BEMLQ+8OKLDE+5WBM+5YJRM">菊池会計事務所</AffLink>には、マイクロ法人のパッケージがあります。記帳、申告書の作成、税務相談、税務署への対応が入って、税理士報酬は月1万円からです。全国からリモートで頼めます。

節税効果の見積額が報酬の見積額を上回る個人事業主やフリーランスが、対象になります。この節税効果の試算は無料です。マイクロ法人を作って、申告まで任せたいときに向いています。含まれる作業の範囲は、事務所に問い合わせると確かめられます。

## 自分でやるか、頼むかを決める3つの問い

迷ったら、次の3つに答えてみてください。申告が重くなる、主な分かれ目です。

1. 会社の課税売上高が、1年で1,000万円を超えそうか
2. 取引先から、インボイスの登録を求められそうか
3. 会社で、配当や分配金が出るものを持つ予定か

全部「いいえ」で、人を雇わず、帳簿付けも自分でできるなら、私と同じ形で自分でやる道もあります。1つでも「はい」なら、税理士に相談してから決める形が合います。

## 次に読むなら

法人にするか、まだ決めていない人は、[計算機の記事](/posts/concept-2-keisanki/)で、個人と法人の負担を自分の数字で比べられます。自分でやると決めた人は、[会計ソフトの記事](/posts/setup-2-kaikei/)を読むと、決算書から申告書まで同じ会社でそろえる理由と費用が分かります。
