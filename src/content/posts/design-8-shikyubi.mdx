役員報酬は、当月分を当月の末日に払うことにしました。社会保険料は、その月の報酬から引きます。会社が国に納めるのは翌月末で、口座振替にしています。

ただし、公式の案内で給与から引けるのは、原則として前月分です。当月控除は、私の判断です。

給与の振込と社会保険料の引落を、どちらも月末にそろえました。お金が動く日は、月に1回です。どうしてそうしたかを、金額と一緒に書きます。

## 支給日は月初か月末、どちらも選べます

支給日は、月末にする会社も、月初にする会社もあります。どちらが正しい、ということはありません。毎月決まった間隔で、同じ額を払うことが大事です。この条件は、[役員報酬の額の記事](/posts/design-1-houshu/)に書いた定期同額給与の話とつながります。

私は月末にしました。決め手は2つです。1つ目は、社会保険料の引落が月末だからです。2つ目は、お金が動く日を月に1回にまとめたかったからです。

## 社会保険料は、払う月と納める月がずれます

社会保険料は、月単位でかかります。そして、会社が国に納めるのは、対象の月の翌月末です。たとえば、ある月の分は、翌月の末日までに納めます。末日が休みなら、次の営業日です。

つまり、保険料の発生と、納める日は1か月ずれます。給与から引く側の私にとって、ここが決めどころでした。前月分を引くか、当月分を引くかです。

| 控除のしかた | 中身 |
| :--- | :--- |
| 翌月控除 | 前月分を、当月の報酬から引く |
| 当月控除 | 当月分を、当月の報酬から引く |

日本年金機構の案内では、事業主は毎月の給与から、前月分の保険料を引けることになっています。つまり、公式に書いてあるのは翌月控除です。当月控除をしてよいかは、確かめられる範囲の公式の案内に明記がありませんでした。

それでも私は、当月控除にしました。理由は、最初の支給から手取りが同じ額になるからです。翌月控除だと、最初の支給では引く保険料がなく、その回だけ手取りが違います。毎月同じ額を同じ手順で払う形にしたかったので、当月控除を選びました。

これは、私の判断です。同じ形にしてよいかは、年金事務所か社会保険労務士に確かめてから決めると安心です。

一度決めたら、途中では変えない前提です。毎月同じ手順で払い続けたいからです。

## 毎月の金額

役員報酬は月45,000円で、据え置きです。社会保険料は、私の都道府県の額で次のとおりです。自分の額は、協会けんぽの都道府県ごとの保険料額表で、報酬月額が当てはまる標準報酬月額の行を見ると分かります。会社だけが払う子ども・子育て拠出金は、別に足します。

| 項目 | 金額 |
| :--- | ---: |
| 役員報酬 | 45,000円 |
| 私が払う社会保険料 | 11,393円 |
| 会社が払う社会保険料 | 11,709円 |
| 社会保険料の合計 | 23,102円 |
| 私の手取り | 33,607円 |

手取りは、報酬から私が払う分を引いた額です。当月控除なので、33,607円が毎月同じです。

源泉所得税は、この報酬だと0円です。0円の月も、所得税徴収高計算書という納付書を、税務署へ出します。e-Taxでも出せます。納期の特例を使うと、出す時期は年2回にまとまります。納期の特例を使う形の話は、[会計ソフトの記事](/posts/setup-2-kaikei/)に書きました。

## 社会保険料は、口座振替にしました

会社が納める23,102円は、翌月末に会社の口座から引き落とされるように、口座振替にしました。口座振替にするには、年金事務所へ申出書を出します。私の出し方と、そのときの経過は、[設立費用の記事](/posts/setup-1-hiyou/#社会保険料の口座振替の申出書の出し方)に書きました。

口座振替が始まるまでは、届いた納付書で払います。始まったあとは、納めに行く手間がありません。

## 給与の振込は、毎月自分で登録します

会社の口座はTrunkで、私の個人口座も同じ三井住友銀行です。給与は、Trunkの給与振込で毎月自分で登録しています。同じ銀行宛なので、振込の手数料はかかりません。

定額自動送金も考えました。毎月同じ額なので、一度決めれば自動で動くからです。ただ、三井住友銀行の定額自動送金は、法人は店頭での取扱いで、取扱手数料がかかります。それより、毎月自分で登録する形にしました。

給与振込は、振込日の数営業日前までに承認しておく必要があります。忘れないように、登録は毎月20日ごろにしています。

## 毎月の流れ

| いつ | 何をする |
| :--- | :--- |
| 20日ごろ | 役員報酬の給与振込を登録して承認する |
| 月末 | 役員報酬の振込。同じ日に、前の月分の社会保険料が口座から引き落とされる設定 |
| 翌月10日 | 源泉所得税の納期限。納期の特例を使う会社は、年2回にまとめる |

毎月の振込の作業は、20日ごろの登録だけです。お金が動くのは、月末の1日にそろいます。

## あなたはどちらにするか

決めるときは、次のように考えてみてください。

- お金が動く日を月1回にまとめたい人：支給日を、社会保険料の引落と同じ月末にそろえる形が合います
- 前の月を締めてから払いたい人：月初に払う形もあります。毎月同じ額を、決まった間隔で払うことだけ守ってください
- 控除を公式の案内どおりにしたい人：翌月控除にします
