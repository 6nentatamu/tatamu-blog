会社を作った日に、社内のルールを書いた規程を2つ作り、使い始めました。規程を使い始めることを、施行といいます。作ったのは、出張旅費規程と、車両借上規程です。

出張旅費規程では、日当を決めました。日当は、出張中の食事代などの細かい出費の代わりに、決まった額で払うお金です。日帰りは2,000円、宿泊を伴うと5,000円です。車両借上規程では、私の車を会社の仕事に使ったとき、会社が私に1kmあたり30円を払う、と決めました。

ひとりの会社で、遠くへ出張することはほとんどありません。それでも作ったのは、規程は使う前に備えておくものだからです。じつは最初の計画では、「旅費規程は作らない」と書いていました。

## 最初は「旅費規程は作らない」と書いていました

計画を立てたとき、私は旅費規程をいらないと判断していました。移動は年に数回しかない、という理由です。

ところが、あとで計画資料を見返すと、旅費規程の設計がすでにありました。私はそれを見ずに「作らない」と書いていたんです。読み直して、考え直した理由は3つです。

1つ目は、車の借上は、出張かどうかと関係がないことです。近くの用事で私の車を使うときも、規程の上では借上料の対象にできます。「移動が少ないから不要」は、日当の話と車の話を混ぜていました。

2つ目は、規程は先に備えておくものだからです。必要になってから作ると、それより前の移動には使いにくくなります。作る手間は、ひな形を埋めるくらいでした。

3つ目は、規程を持つこと自体には、困ることがないからです。日当は、条件に合う出張があったときにだけ出ます。規程があるから毎月もらえる、というものではありません。

それで、計画を直して、会社を作った日に2つとも施行しました。

## 出張と外出を分けて、日当は出張だけ

出張旅費規程では、移動を「出張」と「外出」に分けました。この線は、私が決めた基準です。

| 区分 | 条件 | 日当 |
| :--- | :--- | :--- |
| 出張 | 片道80km以上、または片道2時間以上 | 日帰り2,000円、宿泊を伴うと5,000円 |
| 外出 | 出張に当たらない業務の移動 | なし |

宿泊を伴う出張では、宿泊費の実費も、会社が私に払います。電車やバスの運賃、高速道路の料金、駐車場の料金も、出張でも外出でも、実費を会社が払います。

日当のような出張の旅費は、その旅行に通常必要な範囲なら、受け取る人の所得税がかかりません。通常必要かどうかは、国税庁が税の取扱いの基準として示す基本通達で、2つの見方が示されています。役員と従業員を通じて、バランスの取れた基準か。同じ業種・同じくらいの規模の会社の水準と比べて、相当か、です。

この通達は、日当の額そのものは示していません。私は、低めの2,000円にしました。通常必要な範囲を超えた分は、旅費ではなく役員の給与として扱われます。そうなると、私には所得税がかかり、会社では経費にならないおそれがあります。

設立のころの役所や銀行への移動は、どれも外出に当たりました。日当は出ていません。

## 車は、会社で持たずに1km30円で借りる

車をどう扱うかは、3つの形を比べました。

| 形 | 判断 |
| :--- | :--- |
| 会社で車を買う、またはリースする | 捨てた。私用との分け方を毎回決める必要がある |
| ガソリン代・保険・車検を、走った距離で分ける | 捨てた。レシートの管理と分ける計算が増える |
| 私の車のまま、1kmいくらで会社が借りる | 選んだ。距離に単価を掛けるだけで済む |

単価は1km30円です。この30円に、燃料費、車の価値が下がる分、自動車保険、自動車税、車検をまとめて含めました。なので、ガソリン代などの実費は、別に精算しません。高速道路と駐車場の料金だけは、借上料に含めず、実費で払います。

走った距離は、地図サービスの経路検索で出す決まりにしています。メーターを毎回記録する手間はかけません。

30円の根拠は、規程の中で「算定の根拠を書いた書面を一緒に保管する」と決めました。根拠の書き方の例は、次のとおりです。

- 燃費が1Lあたり15km、ガソリンが1L170円なら、燃料費は1kmあたり約11.3円
- そこに、車の価値が下がる分、保険、税の相当分を足して、1kmあたり約30円

あなたが単価を決めるときも、自分の車の燃費と、ガソリンの値段から始めると、説明できる数字になります。

ただ、距離に単価を掛けて払う借上料を、受け取る役員の税でどう扱うかは、まだはっきりしません。国税庁の通達や案内で、この形にぴったり当たる例を見つけられませんでした。同じ形にするなら、単価の決め方とあわせて、税理士に確かめておくと安心です。

## 精算書は、3つの列に分けて1枚にまとめる

外出しても日当は出ませんが、車を使った分は精算書に書きます。精算書は月ごとに1枚にまとめ、日付、行先、用件、走った距離を書きます。私は、精算書の列を3つに分けました。

| 列 | 何を書くか | 根拠 |
| :--- | :--- | :--- |
| 交通費 | 電車・バスの運賃、高速道路、駐車場の実費 | 規程はなく、実費を払う |
| 車両借上料 | 走った距離×30円 | 車両借上規程 |
| 出張の日当 | 出張に当たるときの日当 | 出張旅費規程 |

列を分けておくと、どの規程にもとづく支払いかが、あとから見ても分かります。

払い方は、2つに分けて考えています。借上料と日当は、精算書をもとに、会社から私へ払うお金です。私が立て替えた運賃などの実費は、会社が私から借りたお金として帳簿に記録し、あとでまとめて返してもらう方針です。

いちばん楽なのは、そもそも立て替えないことです。会社のカードで払えるものは、会社のカードで払っています。そうすると、立て替えの精算がいりません。

## 規程があっても、移動がなければ出ない

気をつけているのは、規程を作ったからといって、毎月なにかが出るわけではない、という点です。条件に合う移動が実際になければ、日当も借上料も出ません。

なので、移動したら、カレンダーに行先と用件を残すことにしています。精算書にも、区間と用件を書きます。実際に移動した記録がある範囲でだけ、払う形です。

## あなたの場合は

規程を作るか迷ったら、次のように考えてみてください。

- 自分の車を仕事で使うことがある人：車両借上規程が先です。単価の根拠を書いた書面も一緒に残します
- 遠くへ出かける仕事がある人：出張旅費規程で、出張の条件と日当の額を決めておきます。額は、同じくらいの規模の会社の水準から考えます
- 車を仕事でほとんど使わない人：出張旅費規程だけでも足ります。電車やバスの運賃は、規程がなくても実費で払えます
- 会社で車を持つか迷っている人：私用と仕事用をどう分けるかを、先に決めておく必要があります

規程は、会社を作るときに一緒に作っておくのがおすすめです。作る手間はわずかで、あとから作るより使える範囲が広くなります。
