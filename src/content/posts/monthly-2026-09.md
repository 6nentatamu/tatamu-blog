法人を設立した最初の月なので、設立にかかった費用と、毎月かかるお金がはじめてそろいました。1円単位でそのまま書きます。

## 結論

- **売上（収入）**：123円
- **毎月かかるお金**：61,573円（役員報酬・会社負担の社会保険料・経費）
- **設立費用**：68,590円（1回だけ。8月の準備費用を含む）

ブログからの収入はまだありません。この月は、ほぼ「出ていくだけ」の月です。

## 収入

| 項目 | 金額 |
| :--- | ---: |
| その他の収入 | 123円 |
| ブログ（アフィリエイト） | 0円 |
| **合計** | **123円** |

「その他の収入」は、法人の事業として受け取っている小さな広告収入です。

## 毎月かかるお金

| 項目 | 金額 | 内容 |
| :--- | ---: | :--- |
| 役員報酬 | 45,000円 | 自分への給料。社会保険に入るための最低限の額 |
| 社会保険料（会社負担分） | 11,709円 | 健康保険・厚生年金の会社が払う側 |
| 通信費 | 4,414円 | AIツールとクラウドサービスの利用料 |
| 旅費交通費 | 450円 | 役所での手続き2回分 |
| **合計** | **61,573円** | |

役員報酬45,000円のうち、手取りは33,607円です。差の11,393円は、自分が払う側の社会保険料として給料から引かれています。つまり社会保険料は、会社負担と本人負担を合わせて**月23,102円**です。所得税（源泉徴収）は、この金額だとかかりません。

なぜ役員報酬をこの額にしたのかは、第2部「役員報酬をいくらにしたか」で詳しく書く予定です。

## 設立費用（1回だけ）

| 項目 | 金額 |
| :--- | ---: |
| 登録免許税（法務局に納める税金） | 60,000円 |
| 電子定款の作成サービス | 5,500円 |
| 法人印鑑（実印・銀行印・角印の3本セット） | 2,220円 |
| 郵便受けに貼る表札（法人名のプレート） | 870円 |
| **合計** | **68,590円** |

8月に払った準備費用も、まとめて設立費用として扱っています。定款を電子にしたことで、紙なら必要だった収入印紙4万円がかかっていません。設立の手順と費用の内訳は、第3部「設立の全手順と費用」で詳しく書く予定です。

## 9月に分かったこと

- **社会保険料は「今月引いて、来月末に払う」**：9月分の社会保険料は9月の給料から引きますが、実際に納めるのは翌月末です。最初はこのずれに戸惑いました。
- **源泉所得税は0円でも申告が要る**：役員報酬が少ないので所得税はかかりませんが、「0円です」という届け出は必要でした。

## 来月の見通し

10月は、毎月かかるお金（約6.2万円）に加えて、9月分の社会保険料の納付があります。ブログを始めたばかりなので、収入はまだ見込んでいません。

収入がこの調子でも、計画は崩れません。法人の目的は、ブログで大きく稼ぐことではなく、社会保険に入りながら資産をゆっくり取り崩すことにあるからです。そのあたりの設計は、第1部「構想」と第2部「設計」で順に書いていきます。
